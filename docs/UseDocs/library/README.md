# 官方标准库

20C 登记官方 Xiao 标准库的源码根目录、工具链加载边界和兼容身份。首批模块已经完成源码与 VM 回归；
原生双路径门控需要受控工具链运行，未取得运行号前仍不能把原生侧写成已验证。

模块实现必须同时更新本页索引、模块 README、阶段 DevDocs 和标准库兼容身份。官方库不通过普通包依赖安装。

## 首批模块

- [`text`](text.md) —— `contains_char(str text, str needle) -> bool`，按迭代器式 `for` 扫描字符。
- [`path`](path.md) —— `join(str base, str leaf) -> str`，按冻结的 `/` 拼接形状生成路径文本。

首批接口是标准库接口版本 1 的兼容新增；数字格式化、切分/切片、大小写转换、路径规范化和文件系统访问不在本批。
