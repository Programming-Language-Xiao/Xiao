# 开始使用

适合第一次接触 Xiao 的读者。本主题说明安装、验证和运行第一段程序的完整路径。

## 前置知识

会使用终端并能编辑一个文本文件即可；不要求先了解 Rust、TypeScript 或编译器实现。

## 推荐顺序

1. [安装与平台准备](installation/README.md)
2. 完成后回到[语言指南](../language/README.md)
3. 需要隔离依赖时转到[工具与交互](../tooling/README.md)

## 当前状态

安装步骤将在对应平台工具链完成并通过测试后标记为 `verified`。在此之前不要把示例命令当作可执行承诺。
