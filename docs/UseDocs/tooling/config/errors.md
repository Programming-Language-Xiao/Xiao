# 配置错误与修复

配置错误会在运行、构建或安装前报告，并包含源码位置和稳定编号。修复文件后重新
执行原命令即可；读取配置不会执行任何用户代码。

## 常见编号

| 编号 | 含义 | 修复方式 |
| --- | --- | --- |
| `X05-CONFIG-001` | 顶层出现键值语句 | 把字段放入 `[project]` 等表中 |
| `X05-CONFIG-002` | 出现函数、调用、控制流、导入或表达式 | 改为字面量声明 |
| `X05-CONFIG-003` | 表内键重复 | 删除重复键或合并为一个值 |
| `X05-CONFIG-004` | 配置字段值类型不符合模式 | 按模式要求的类型改写字面量 |
| `X05-CONFIG-005` | 严格表出现未知字段 | 检查字段拼写和当前阶段白名单 |
| `X05-CONFIG-006` | 顶层表未知 | 使用已登记表，或等待对应工程期 |
| `X05-CONFIG-007` | 缺少项目身份 | 补齐 `[project].name` 和 `version` |
| `X05-CONFIG-008` | 导出路径不安全或扩展名错误 | 使用项目根相对的 `.xiao` 路径 |
| `X05-CONFIG-009` | 表头形状非法 | 使用 `[表名]` 形式，不要嵌套或留空 |
| `X05-CONFIG-010` | 字面量、数组或字典结构非法 | 检查括号配对与元素类型是否一致 |
| `X05-CONFIG-011` | 字典/数组分隔符错误 | 字典键值使用 `=`，元素使用逗号 |
| `X05-CONFIG-012` | 表头重复 | 保留一个同名表头 |

## 典型错误

下面的写法会失败，因为配置不能调用函数：

```xiao
[project]
name = input("name")
version = "0.1.0"
```

应直接写入静态字符串，或由未来 CLI 配置命令在写回前完成值校验。`[main]` 也不能
放进 `config.xiao`；它只属于 `.xiao` 源文件入口语法。

## 仍未实现的能力

依赖求解、锁文件、多包源、虚拟环境、语言包插件和优化配置不会被 05-D 错误页面
提前承诺。遇到相关字段被拒绝时，先确认对应工程期是否已经实现，再查看[工具与交互]
主题索引。
