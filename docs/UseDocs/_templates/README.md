# UseDocs 页面模板

新增页面时复制适合的模板，并把页面加入主题索引、模块登记和相关故障排查页。模板只约束机器字段，不替代面向自然人的说明。

## 必备元数据

```yaml
---
id: language.basics.variables
title: 变量与类型
status: planned
audience: beginner
module: xiao-types
stage: "02"
related:
  - ../README.md
---
```

`status` 只有在代码、测试、示例和链接检查均通过时才能改为 `verified`；废弃页面必须提供替代页面链接。
