# Runtime 对象与表生命周期

本目录说明 Xiao 运行时对象、句柄、表实例生命周期及错误展开规则。内容对应开发阶段 06-B；它描述当前已验证的运行时边界。VM 与容器 Runtime 已由 09 阶段交付，语言级并发模型仍归 `07-D`。

## 阅读路线

1. [对象与句柄](objects-and-handles.md)：了解强引用、弱引用和释放时机。
2. [表生命周期](table-lifecycle.md)：了解 `[Table]` 与 `[[Table]]` 的运行时状态。
3. [错误与展开](errors-and-unwind.md)：了解初始化失败、清理失败和主错误保留规则。
4. [运行时错误报告](../../../troubleshooting/errors-and-reports.md)：了解统一错误码、Fatal 边界、原因链和堆栈报告。

## 当前边界

- 首版引用计数为单线程、非原子策略，句柄不得跨线程传递。
- 表字段类型和可见性必须来自已通过静态检查的签名，运行时不会动态新增成员或改型。
- `lint`/`lfloat`已完成B2-A在ABI1.18/生成器20内部快照的精确算术、转换、值承载和三平台资源/性能验收；数值文本边界不暴露Rust对象布局，每次操作的临时大数在调用结束后释放。新增数值范围最终发布仍planned，`lfloat_divide`/`cmath`和1.19/21最终产物留后续批次；详见[转换与资源边界](../../basics/types/conversions.md)。
