# 静态标量类型

本主题介绍 Xiao 当前已验证的 S0 类型检查：名称绑定、标量声明、常量、数值提升、
布尔奇偶加减和显式转换。它描述的是编译期行为；完整程序执行仍需后续 Runtime 阶段。
