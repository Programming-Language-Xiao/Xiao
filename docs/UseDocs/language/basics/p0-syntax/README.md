# P0 最小语法入口

本子主题说明 Xiao 0.1 已验证的最小 AST 语法入口：独立字面量、名称、简单赋值、
顶层语句、文档注释关联和错误恢复。它是给自然人阅读的使用说明，不代表 Xiao
已经能够执行这些语句。

## 阅读顺序

1. [语句与赋值](statements.md)：从单条表达式到多条顶层语句。
2. [错误与当前边界](errors.md)：错误提示、恢复位置和暂未开放的语法。

## 前置与后续

请先阅读[基础变量与表达式](../README.md)以及[源码位置与最小 Token](../../lexical/README.md)。
容器、函数和类型规则会在后续版本逐步开放；P1 已在[表达式与选择器](../p1-expressions/README.md)
中开放运算、调用和选择器的语法树，但本页仍专门描述 P0 兼容子集。不要把任一页面的
语法形状当作已经可执行的运行时值或静态类型承诺。
