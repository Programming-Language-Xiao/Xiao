# 模块与工程

本主题将说明文件模块、导入导出、`config.xiao` 依赖关系和项目入口。

## 前置知识

先完成[基础变量与表达式](../basics/README.md)，并了解[开始使用](../../getting-started/README.md)中的项目目录概念。

## 页面规划

导入路径、依赖源、循环依赖和导出约束会与包管理器实现同步发布。页面不得要求用户创建 Python 风格的 `__init__.py`，但只有通过对应规格测试后才可标记为 `verified`。
