本主题按“语法 → 项目发现 → 作用域/导出 → 错误”阅读，说明当前已验证的本地 `.xiao`
模块边界。包管理器、`config.xiao` 依赖解析和外部源会在后续阶段单独加入；本主题不要求
创建 Python 风格的 `__init__.py`。
