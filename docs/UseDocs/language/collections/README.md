# 容器与集合

本主题按实现阶段说明数组、元组、集合、字典表、字典列以及索引和范围选择。当前已验证
的是 C0/C1 的有序容器静态闭环，以及 C2-A/C2-B 的集合静态闭环：容器字面量、结构化
类型、声明路径、精确读取、高级选择计划、集合元素约束、异构成员并集和成员判断。真实
Runtime 容器读写、自动扩容、集合对象和集合运算仍在后续阶段。
