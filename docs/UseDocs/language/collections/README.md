# 容器与集合

本主题按实现阶段说明数组、元组、集合、字典表、字典列以及索引和范围选择。当前已验证
的是 C0/C1 的有序容器静态闭环，以及 C2-A/C2-B/C2-C 的集合静态闭环：容器字面量、结构化
类型、声明路径、精确读取、高级选择计划、集合元素约束、异构成员并集、成员判断和集合
运算类型推导。09R2 研究 VM 已执行有序容器的精确读取、高级选择、广播写入，以及
集合对象、集合代数、比较、成员判断，以及六类容器的 `for` 迭代；自动扩容、集合增删和
正式生产 `xiao run` 仍在后续阶段。
