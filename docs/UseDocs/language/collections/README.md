# 容器与集合

本主题按实现阶段说明数组、元组、集合、字典表、字典列以及索引和范围选择。当前已验证
的是 C0/C1 静态闭环：容器字面量、结构化类型、声明路径、精确读取和高级选择计划；真实
Runtime 容器读写、自动扩容和集合仍在后续阶段。

## 前置知识

先阅读[基础变量与表达式](../basics/README.md)。
