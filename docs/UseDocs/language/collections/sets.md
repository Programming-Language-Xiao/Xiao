# 集合与成员判断

本页说明 C2-A 已验证的集合静态边界。集合是无序容器：元素的书写顺序只用于
源码诊断和测试输入，不能被程序当作迭代顺序或索引使用。C2-A 只建立语法、
静态类型和诊断；当前 Runtime 尚未创建或修改真实集合对象。

## 创建集合

非空花括号中只写值时表示集合：

```xiao
ids = {1, 2, 3}
names = {"xiao", "rust"}
flags = {true, false}
empty = set()
```

`set()` 是空集合构造式，C2-A 要求它没有参数。空花括号 `{}` 仍然表示空字典表，
不能把它写成空集合：

```xiao
empty_set = set()
empty_table = {}
```

花括号中出现 `键 = 值` 条目时表示字典表；同一个花括号不能混用集合值条目和
字典键值条目。字典表的说明见[字典表与字典列](dictionaries.md)。

## 显式元素类型

显式类型约束的是“每个成员允许的类型”，不是位置，也不会给无序集合增加顺序：

```xiao
int ids = {1, 2, 3}
str names = {"xiao", "rust"}
bool flags = {true, false}
```

C2-A 中未写显式类型的集合必须能推断出单一元素类型。`bool` 是独立类型，不能
与整数或浮点值合并；`none` 可以作为独立的可哈希元素。真正的异构集合属于后续
C2-B，不要依赖它在当前版本通过检查。

## 唯一性与可哈希性

集合中的相等元素只能出现一次。能够在编译期确定的重复标量会直接报告诊断。
集合元素必须可哈希，哈希值在元素位于集合期间必须稳定。C2-A 可直接验证标量
和 `none`；数组、字典表、字典列、普通集合等可变容器不能作为集合元素。元组的
递归可哈希扩展留给后续集合阶段。

集合不提供数字索引、键名索引、范围、步长或随机选择。对集合使用 `values[0]`
或其他选择器会产生容器选择诊断，而不是返回某个“看起来像第一项”的值。

## 成员判断

`in` 和 `not in` 的结果类型固定为 `bool`：

```xiao
ids = {1, 2, 3}
has_two = 2 in ids
missing = 4 not in ids
```

右侧必须是集合，左侧值必须满足集合的元素类型约束。集合代数（包括 `+` 并集、
`&` 交集、`-` 差集和 `^` 对称差）、成员增删和 Runtime 求值尚未在 C2-A 开放。

## 常见边界

- `{}` 是空字典表；空集合必须写 `set()`。
- 集合无序，不能通过索引读取，也不能依赖某次运行的显示顺序。
- `bool` 不会被当作整数，`{true, 1}` 在 C2-A 不会被合并成同一类型集合。
- 显式 `int` 集合不能加入字符串、布尔值或其他不兼容成员。
- `frozenset` 不属于当前阶段。
