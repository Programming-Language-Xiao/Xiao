# 高级选择与结果形状

本页说明 Xiao 0.1.0 在 C1 类型阶段已经验证的有序容器选择语法。数组、元组、`str` 和
字典列可以使用同一对方括号完成多选和范围选择；字典表只能精确按键读取，集合完全不可
索引。当前版本的类型检查器生成选择计划和诊断，后续 Runtime 才会把计划应用到真实值。

## 多选与范围

所有选择项写在同一对方括号中，数字位置从 `0` 开始：

```xiao
items = ("a", "b", "c", "d")
items[0, 2]       # ("a", "c")
items[1~3]        # ("b", "c", "d")
items[<2]         # ("a", "b")
items[<=2]        # ("a", "b", "c")
items[>1]         # ("c", "d")
items[>=1]        # ("b", "c", "d")
items[=]          # 全部元素
```

`start~end` 是两端都包含的闭区间。`<`、`<=`、`>`、`>=` 分别表示不包含或包含单边
边界。选择项按书写顺序保留，重复项和重叠范围不会自动去重。范围没有命中任何元素时，
返回与来源根容器同类型的空结果；单个精确索引越界仍然报错。

## 负索引与嵌套路径

数字索引支持 Python 风格负索引，`-1` 表示最后一个位置。斜杠表示继续进入嵌套容器，
而不是除法：

```xiao
items = ("a", "b", [1, 2])
items[1, 2/1]       # ("b", [2])
items[1~2/1]        # ("b", [1, 2])
```

类型阶段按有序容器的深度优先路径重建结果。范围端点切入嵌套分支时只保留命中的后缀，
没有被边界切入的中间分支保留为完整容器；同一父容器下的多个路径会合并回数组或元组形状。
`str` 使用 Unicode 码点作为索引单位，无法静态确定长度的字符串位置会留下运行时边界检查。

## 步长

在来源表达式和方括号之间写 `{step}`，可以作用于全选、单边范围、闭区间和每个多范围
项目：

```xiao
items{2}[=]
items{-1}[0~3]
items{2}[0~2, 1~3]
```

步长必须是整数语义值。正数按正向每隔指定位置选择，负数先反向再按绝对值取值；零没有
合法含义，静态零值会报告 `X03-TYPE-009`，动态零值由 Runtime 报错。动态步长只在类型
阶段登记检查，不会被默认为 `1`。

## 类型和边界

单项精确选择返回被选元素的类型；多选和范围保留来源根容器及必要的嵌套形状。字典列的
数字索引和键名索引可以混用，但同一直接键被重复选中时结果改为按选择顺序排列的元组，
以避免产生重复键的字典列。对字典表使用范围、多选、步长或随机项会报告
`X03-TYPE-008`；集合不提供索引接口。
