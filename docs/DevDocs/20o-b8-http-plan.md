# 20O-B8. HTTP 客户端/服务端实施规划

> **B8 尚未开始；B3 与 B7 完成并通过安全/网络审阅后才有 B8-0 探测/冻结入口。**
> B8 覆盖 HTTP 客户端/服务端、超时、限制、取消、连接/关闭 drain；不实现数据库（B9）。
> TLS 只使用 B7 冻结的引擎/策略，不自研 TLS/HTTP 协议栈；默认校验、失败关闭。
> 不跑旧721；registry/教程在验证范围升级。

## 一、入口与范围

| 项 | 当前状态 |
| --- | --- |
| B3 | 简单宿主库尚未完成；B8 依赖 time/取消/宿主能力 |
| B7 | 安全批尚未完成；B8 依赖其 TLS 引擎/策略/随机/哈希边界 |
| B0 | D-12 网络方向已确认：成熟依赖、TLS默认校验、强制限额/超时、未经安全审阅不发布 |
| 本批目标 | HTTP client/server、超时/限制/取消/关闭drain |
| 未做 | HTTP/2/3、代理、WebSocket、HTTP缓存、数据库(B9) |
| 状态 | http初始未登记；验证/审阅后按范围升级 |

B8 是 **网络协议批**，不是安全批或数据库批。HTTP 头部/正文/分块/keep-alive/关闭 drain 必须默认有界，不能把宿主默认行为直接暴露成语言契约。

### 1.1 要做

1. 探测成熟HTTP候选实现/依赖/版本/特性/许可证/维护/安全公告；
2. 冻结HTTP版本/方法/状态/头/正文/分块/keep-alive/重定向范围；
3. 冻结client请求/响应/超时/取消/连接池/关闭drain；
4. 冻结server监听/路由/请求/响应/并发/关闭drain；
5. 冻结TLS与B7引擎/策略接线，默认证书/主机名校验；
6. 冻结头部/正文/连接/请求速率/超时/重定向/并发上限和错误；
7. 实现client/server、教程/示例/错误/资源/安全测试；
8. 接通类型/IR/TAC/VM/LLVM/归档、std/stdlib双路径、能力/隔离；
9. 安全/网络审阅、三平台/CI、registry按验证范围升级。

### 1.2 明确不做

- 不实现HTTP/2、HTTP/3、WebSocket、代理、缓存；
- 不实现数据库/驱动（B9）；
- 不自研TLS/HTTP协议栈；不提供跳过校验/降级/无限重定向；
- 不改变B3/B7语义、B2-B6数值/值模型/工具边界；
- 不新增未冻结能力位/错误码/intrinsic/ABI；
- 不提前升级registry/教程，不跑旧721。

## 三、分批执行

### B8-0：探测、冻结与安全审阅计划

1. 冻结威胁模型：恶意服务端/客户端、超大头部/正文、慢loris、请求走私、重定向循环、取消/关闭竞态；
2. 探测候选HTTP依赖/版本/特性/许可证/维护/漏洞/三平台；
3. 冻结HTTP版本（建议先HTTP/1.1；HTTP/2/3后置需明确裁定）、方法/状态/头/正文/分块/keep-alive；
4. 冻结client：
   - 请求方法/URL/头/正文/响应；
   - 重定向/超时/取消/连接池/关闭drain；
   - TLS选择/B7策略；
5. 冻结server：
   - 监听/路由/请求/响应/并发；
   - 超时/慢loris/请求体/头/连接上限；
   - 关闭drain/取消；
6. 冻结头部/正文/连接/请求速率/重定向/并发/超时上限和错误身份；
7. 冻结TLS与B7接线：默认校验、SNI/主机名、协议/套件、失败关闭；禁止跳过校验/降级；
8. 冻结函数签名/参数/返回/效果/所有权/能力/错误码/资源/性能预算；
9. 按20P D-15静态内置依赖，固定版本/特性/锁/许可证/审计来源/`--locked`；不自研协议；新增intrinsic/ABI按20P另立；
10. 安全/网络审阅清单：TLS、头/正文上限、走私、慢loris、重定向、取消/关闭、日志脱敏、能力；
11. client/server教程草案、固定示例、registry候选（planned）；
12. 记录后置能力（HTTP/2/3、WebSocket、代理、缓存）。

退出：HTTP版本/API/限制/错误/TLS/依赖/审阅计划冻结；未写产品。
