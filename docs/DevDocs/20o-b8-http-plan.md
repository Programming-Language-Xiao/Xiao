# 20O-B8. HTTP 客户端/服务端实施规划

> **B8 尚未开始；B2-C最终收口、B3及B7安全审阅完成后才进入产品实施。前置未完成时，仅可经明确授权执行B8-0探测/冻结。**
> B8 覆盖 HTTP 客户端/服务端、超时、限制、取消、连接/关闭 drain；不实现数据库（B9）。
> TLS 只使用 B7 冻结的引擎/策略，不自研 TLS/HTTP 协议栈；默认校验、失败关闭。
> B8 不回写 B2-C/B3/B7 历史快照；不跑旧721；registry/教程仅在功能、平台与安全审阅范围通过后升级。

3. 冻结client请求/响应字节表示、超时预算/取消/连接池/关闭drain、重定向/重试/凭据范围；
4. 冻结server绑定默认值/路由与路径规范化/处理器并发/请求解析/响应/关闭drain；
5. 冻结TLS与B7引擎/信任策略接线，默认证书/主机名校验及不降级规则；
6. 冻结头部/正文/连接/请求速率/总超时/重定向/并发/队列/keep-alive上限和错误优先级；
7. 实现client/server、教程/示例/错误/资源/安全测试；
8. 接通类型/IR/TAC/VM/LLVM/归档、std/stdlib双路径、能力/隔离；
9. 安全/网络审阅、三平台/CI、registry按验证范围升级。

### 1.2 明确不做

- 不实现HTTP/2、HTTP/3、WebSocket、代理、缓存；
- 不实现数据库/驱动（B9）；
- 不自研TLS/HTTP协议栈；不提供跳过校验/降级/无限重定向、隐式代理/重试或Cookie全局状态；
- 不改变B3/B7语义、B2-B6数值/值模型/工具边界；
- 不新增未冻结能力位/错误码/intrinsic/ABI；

## 三、分批执行

### B8-0：探测、冻结与安全审阅计划

1. 冻结威胁模型：恶意服务端/客户端、攻击者控制URL/头/正文、超大输入、慢速发送、解析差异/请求走私、DNS变化、重定向循环、取消/关闭竞态；明确本库是否防护应用层SSRF及其边界；
2. 探测成熟HTTP实现及版本/特性/许可证/维护/安全公告/三平台构建；绑定依赖锁和真实源码/工具身份，不手写HTTP解析器；
3. 冻结HTTP版本/RFC子集（首批HTTP/1.1及对应HTTP语义/消息语法RFC版本）、方法白名单/状态/头/正文/分块/Trailer/Expect/100-continue；默认拒绝CONNECT/TRACE/Upgrade/隧道与pipelining，例外须另裁定；HTTP/2/3、WebSocket后置；
4. 冻结消息解析与请求走私防护：CRLF/obs-fold/非法字段名、重复Host、重复或冲突Content-Length、Transfer-Encoding与Content-Length并存、chunk边界/溢出/Trailer的处理必须唯一且有负例；禁止前置代理与后端解析歧义，无法接受时整次拒绝并关闭连接；
5. 冻结client：
   - URL scheme/authority/userinfo/端口/IDNA/百分号编码和请求方法/头/二进制正文/响应表示；冻结允许的http/https scheme及用户信息处理；
   - 明确loopback/private/link-local/multicast目的地址策略；若限制，须在DNS解析后和每次重定向后复核解析地址以防DNS rebinding；若不限制，清楚说明network能力授予的宽泛访问范围及调用方SSRF责任；
   - 每跳与总截止时间、DNS/连接/读写超时、取消清理、连接池/每主机与全局上限/关闭drain；
   - 自动重定向默认关闭；若开放，冻结状态码/次数/循环/跨origin认证头、Cookie与客户端证书隔离/HTTPS降级/方法与正文重放；禁止默认自动重试非幂等请求；
   - 无隐式代理、Cookie jar、环境代理读取、Content-Encoding自动解压；若有明确扩展，必须独立冻结资源与凭据规则；TLS只调用B7冻结策略且不得协商到B8未支持的协议；
   - 冻结完整物化或流式API；若完整物化，所有请求/响应体须在公布前满足绝对字节上限；若流式，另冻背压、取消、部分交付和释放协议；
   - 连接池身份至少区分scheme/host/port/TLS策略/客户端身份；
6. 若B7未交付B8所需TLS角色/传输适配，退回B7另批，不在B8私自实现第二套TLS；
7. 冻结server：
   - 默认绑定地址（建议loopback）、显式暴露到其他接口的方式/能力、端口0/重复bind与平台错误；
   - 路由/处理器签名和调用方式、原始request-target/百分号解码/点段、编码斜线/无效UTF-8处理；处理器并发/有界队列容量/每连接请求数；
   - 每请求/总截止时间、头/正文读取速率、慢速客户端处理、keep-alive空闲时限、TLS接线；
   - 关闭时停止接纳、取消未开始请求、已运行处理器如何drain及截止后关闭连接；响应头防CRLF注入、禁止冲突framing；不得创建无界隐藏线程/任务队列；
8. 冻结请求/响应头重复字段语义、Hop-by-hop字段处理、Content-Length/Transfer-Encoding唯一规则、压缩内容和Trailer行为；二进制正文所有权、输出上限及失败原子性；
9. 冻结全局/每连接/每主机的头部字节数、正文、并发连接、排队请求、速率窗口/单调计时来源及限流键、keep-alive、重定向和超时上限；冻结请求/响应日志对userinfo、query token、Authorization/Cookie、敏感头和正文的脱敏；给出错误身份/优先级及TLS错误脱敏；
10. 冻结能力边界：网络位必须在DNS、bind、connect和读写宿主流之前检查；缺位负例确认无DNS/套接字副作用；证据与`.xar`实际所需能力一致，不新增/复用未冻结位；
11. 冻结client/server精确签名、参数/返回/效果/所有权/资源/性能预算；明示各阶段截止时间共用总预算，不因重定向/重试重置；
12. 按20P D-15静态内置依赖，固定版本/特性/锁/许可证/安全公告/审计来源/`--locked`，禁止运行时任意动态加载；冻结新增Runtime值/intrinsic/ABI/生成器/标准库接口/`.xiaoc`/`.xar`身份和旧产物拒绝/缓存规则，不回写历史基线；新增intrinsic/值类型按20P升级ABI并更新指纹，保留既有编号和ID 100墓碑；
13. 建立安全/网络审阅清单：TLS信任、请求走私差异、头/正文/速率/连接上限、SSRF/重定向、DNS变化、取消/关闭、日志脱敏/能力；定严重度和未解决风险签收规则；
14. client/server各写完整教程章节（同一`docs/UseDocs/library/http.md`，按D-20配固定示例），进入VM/受控原生逐字输出与退出码CI；示例只依赖隔离的本地服务/测试证书，不依赖公共互联网或共享服务；registry保持planned；
15. 记录延期能力（HTTP/2/3、WebSocket、代理、Cookie/缓存、自动解压等）。

退出：协议子集、消息解析/走私拒绝规则、API/TLS/能力、限制/错误/依赖/版本、审阅计划和client/server两章教程冻结；未写产品，也不由B8-0本身授权产品并行实施。

### B8-1：HTTP 客户端

1. 按冻结的HTTP/1.1子集实现请求/响应、头、正文、分块与连接复用；
2. TLS默认校验、总截止时间/DNS/连接/读写超时、真实取消与连接池/关闭drain；
3. 默认不自动重定向/重试；启用行为严格遵守跨origin凭据剥离、HTTPS降级与重放规则；
4. 无network能力时在DNS前拒绝；限制URL/头/正文/连接/队列/重定向，拒绝 framing 歧义；
5. 局部HTTP服务互操作、DNS/取消/响应畸形/资源负例、安全测试和离线教程。

退出：client内部可用；TLS默认校验，网络能力有效，有界/可取消且无隐式降级。

### B8-2：HTTP 服务端

1. 默认loopback监听；非loopback绑定显式指定且网络能力不足时在bind前拒绝；路由/处理器/请求/响应/并发按冻结API；
2. 头/正文/连接/队列/速率/截止时间/慢速发送与空闲keep-alive上限；请求 framing 歧义立即拒绝并关闭连接；
3. 有界调度、取消/关闭drain、已运行handler清理及截止后套接字关闭行为；
4. TLS仅按B7冻结能力与策略接线，证书失败不得降级为明文；
5. 走私/慢速请求/资源/取消/关闭/并发压力和本地互操作测试；教程只访问隔离本地服务。

退出：server内部可用；无能力不bind、有界/可关闭，抗慢速连接和消息走私的冻结负例通过。
