# 20O-B2-C. B2 最终公共收口与发布规划

> **B2-C 尚未开始；B7 完成、B2-B 内部 1.19/21 收口后才有开工入口。**
> 入口为 B7 固定的最终 1.19/21 源码/证据与 B6 资源/性能结论；B2-B 内部可用不等于公共发布。
> B2-C 只做最终 721、三平台公共产物、最终教程/registry、发布证据和 B2 收口。
> 不新增数学/ABI/intrinsic，不关闭 22C/22D、19/11/22 或 B1 历史债务。

## 一、入口与范围

| 项 | B2-C 开工时需要 |
| --- | --- |
| B7 | B2-B 内部 1.19/21 收口、B1 20入口/17资源/双精确/28守卫、A0～A7/B0～B6对账 |
| B4～B6 | cmath 语言/双路径/归档、1.19/21拒绝/缓存、资源/性能/三平台证据 |
| 最终版本 | ABI 1.19、生成器 21、标准库接口 1、intrinsic 1～48 |
| 最终公共面 | `std.cmath`/`stdlib.cmath` 15包装、`lfloat_divide`、B1七库 |
| 未做 | 关闭历史债务、B3/B4后续项目阶段（不在B2-C） |
| 历史 | 旧721只作为B1历史；B2-C在新快照完整重跑；22C/22D、19/11/22保持独立 |

B2-C 是 **B2 最终公共发布批**，不是 B2-B 内部收口的重复。只有最终 1.19/21 快照、完整 721 和三平台公共产物全部成立，才能把 `stdlib.cmath` 和新增 numeric 范围升级为最终状态。

### 1.1 要做

1. 固定 B7 最终 1.19/21 源码、锁、Runtime、工具链和证据；
2. 在新快照完整重跑 B1 七库 721 条 F10，不继承旧报告；
3. 重跑 B1 20 入口/资源 17/双精确/28 守卫；
4. 收齐 Windows/Linux/macOS 公共产物与 VM/原生 O0/O3 证据；
5. 收齐 cmath/lfloat 语言、双路径、归档、拒绝矩阵、缓存和性能；
6. 最终教程/示例和 registry 只在已验证范围升级；B1既有 verified 保留；
7. 保存发布级源码/产物/CI/平台身份和失败样本；
8. 形成 B2 最终收口报告与后续入口。

### 1.2 明确不做

- 不新增/修改 intrinsic 49+、C 符号、ABI/容器 schema；
- 不重新裁定数学/舍入/域/错误语义；
- 不用旧 721 报告或 B2-B 内部性能代替最终结果；
- 不关闭 22C/22D、19/11/22 或 B1 历史债务；
- 不把内部 1.19/21 证据写成公共发布，直到三平台/721/教程/registry全部完成；
- 不把 B2-C 扩成后续项目阶段。

2. B4-5 内部语言、B5版本矩阵、B6资源/性能均通过；
3. 15项 cmath、30条导入、双路径/归档/序列化可复现；
4. ABI 1.19/生成器21/接口1、旧/新拒绝、缓存稳定；
5. 三平台目标/工具链/CI可用；
6. 最终教程/registry草案只覆盖已验证范围；
7. 旧721、22C/22D、19/11/22保持独立；
8. 唯一发布任务根、独立target/Runtime/缓存已建立。

## 三、分批执行

### B2-C0：最终快照与发布基线

1. 固定 B7 最终完整源码提交、两个Cargo.lock、Runtime/工具链/目标；
2. 复核1.19/21/接口1、intrinsic1～48、ID100墓碑；
3. 固定B1七库源码/错误表/预算/释放断言；
4. 固定三平台公共产物目标、CI工作流和缓存策略；
5. 固定最终教程/registry候选范围；
6. 记录历史债务和A0原始失败身份；
7. 保存发布基线。

退出：最终快照/产物目标/公共范围可复现；未开始发布。

### B2-C1：完整 B1 721 条 F10

1. 在新1.19/21快照完整重跑B1七库721条F10；
2. 覆盖原生/VM、三平台、O0/O3和正式归档；
3. 不启用旧报告、不挑选子集、不改F10阈值；
4. 运行20入口/资源17/双精确/28守卫；
5. 失败样本保留原归属；
6. 保存源码/Runtime/工具/平台/PID/日志/产物摘要；
7. 与B1历史721报告分列，不合并成绩。

退出：最终721完整通过或失败明确；旧报告未冒充。

### B2-C2：最终语言、双路径与归档

1. cmath/lfloat类型/IR/TAC/VM/LLVM/序列化全链路；
2. `std.cmath`/`stdlib.cmath`双路径、导出/移除、普通包隔离；
3. 真实`.xar`/`.xiaoc`、加载器、重放；
4. 002/009/011/012/013/033/034、span/catch/Pure；

6. B1七库回归；
7. 保存三平台/VM/原生证据。

退出：最终语言/双路径/归档成立；无未登记行为变化。

### B2-C3：三平台公共产物与版本矩阵

1. Windows/Linux/macOS公共产物；
2. ABI1.19/生成器21、旧/新拒绝、缓存重生成；
3. VM release、原生O0/O3；性能结论与B6对应；
4. 三平台CI run/job/attempt、路径过滤按事实；
5. 缺平台/不可验证项明确，不放宽预算；
6. 不修改工作流阈值/超时补绿。

退出：三平台公共产物/版本/性能证据完整；失败/不可验证项明确。

### B2-C4：最终教程、示例与 registry

1. `stdlib.cmath` 15包装最终教程/示例；
2. `lfloat_divide`/lfloat/lint新增范围最终说明；
3. B1七库既有verified保留；
4. 只把已验证最终范围升级verified；未验证/planned不扩大；
5. 教程示例逐字进入VM/原生黄金；
6. 不新增未交付模块；
7. 保存教程/registry/兼容身份/文档门禁。

退出：最终教程/registry与证据一致；既有verified不被降级。

### B2-C5：发布证据、收口与后续入口

1. 汇总721/语言/双路径/归档/版本/缓存/三平台/教程/registry；
2. 保存最终源码/锁/Runtime/工具/目标/产物/CI身份；
3. 复核22C/22D、19/11/22、B1历史债务独立；
4. 复核A0原始失败、B1旧721历史未被改写；
5. 形成B2最终收口报告；
6. 记录后续项目入口；
7. 不把B2收口扩成后续阶段发布。

退出：B2最终公共证据完整；B2-C收口；历史债务未关闭；后续入口明确。
