# 20C-第三批. 复探、状态收口与欠账对账

> **背景**：[20C-语言边界批](20c-language-boundary-and-operators.md) 已收口——三轮修补、两条语义裁定、
> §四/§五 双路径接通，`main` 全绿（运行号见该文与[门禁修复专项](20c-native-gates-red-fix.md)）。
> 本批承接它 §六 冻结的**复探**，并把首批两模块的状态收口。
>
> **一句话概括**：**先把欠账点清并关掉能关的**，再按 §六 的规矩**真跑复探**，
> 由结果决定下一步是继续库批次还是转语言批次；首批 `draft → verified` 在本批收口
> ——它的第②条件（CI 双路径运行记录）**已经具备**。

> 状态：**复探与状态收口已完成（2026-10-14）**。四个候选均被既定边界挡住，依据 §八第 1 条选择乙；
> `int → str` 只作为下一批的最小范围，已先完成结果汇报，未在本批顺手实现。

## 一、本批为什么是这三件事

1. **复探是上一批明确冻结的下一步**：[20C-语言边界](20c-language-boundary-and-operators.md) §六
   写明「§四 落地后，**重跑第二批被挡住的候选**」，并规定「复探结果**决定下一批是库批次还是下一个语言批次**」；
2. **状态收口现在才具备条件**：首批两模块的 `draft → verified` 第②条件要求
   「VM/LLVM 双路径证据来自受控环境或 CI 的可复核运行记录」——
   **本轮 CI 已把它满足**（§四 给出运行号）；
3. **欠账必须先点清**：本仓库已经因为「合并登记」「枚举漏项」吃过多次亏
   （F-3 → G-1 → 遮蔽 → §5.2.1）。开新工作前先把**能关的关掉、该改的措辞改回事实**。

## 三、复探（**先做，成表**）

### 3.1 口径（**原样沿用第二批 §3.2**，逐字相同）

1. **真写、真跑**，VM 与 LLVM 原生**两条路径**都跑；
2. **逐条记录**：**成功**，或**在哪一层以什么错误码停下**（解析/类型/IR/原生后端/链接）；
3. **成表呈现**，**不用**「大部分能写」；
4. **不许绕开**：不许用变量下标、不许加临时 intrinsic、不许把逻辑下沉 Rust；
5. **一个夹具只允许一个「待解释的拒绝」**——上一批踩过（前端错误把后端缺口盖住）；
6. 结论**先汇报**再继续。

3. **条件③没核完不许翻**——尤其「示例注明适用版本」这条，**逐条核**并在实施记录里写明核了什么；

5. **不许**把 `stdlib.xiao-standard-library`（骨架条目）一并翻——它是**骨架**不是完成模块，
   口径见 §4.3。

### 4.3 骨架条目怎么办

`docs/module-registry.json` 里有两条 `stdlib.*`：骨架条目与首批条目。
**只翻首批条目**；骨架条目维持 `draft`，并**在它的条目或文档里写明「骨架，不适用 verified」**——
免得后来人看到同一命名空间下两个状态不同而来回改。

## 五、由复探结果二选一（**先汇报，再定**）

### 5.1 甲：**若复探解封了至少一条** → 继续库批次

按 §3.3 第 3 条把解封的操作列进清单；**其余仍被挡的照旧登记**——
**不许**因为一条解封就把整体写成「库能继续了」。

### 5.2 乙：**若四条仍全被挡**（预期） → 下一个语言批次

**最小范围：`int` → `str` 转换**（`X02-TYPE-006`）。理由（审核倾向，**未裁定**）：

1. 它是四条候选里**唯一被两处共用**的前置——大小写转换（`str(int(c) + 32)`）
   与**数字格式化**都要它；
2. 它的位置最靠前：`and`/`or` 接通后，大小写转换的**唯一剩余阻塞**就是它
   （语言边界批 §2.4 已把两个阻塞项拆开登记）；
3. 它比「容器参数类型」与「非字面量下标」**面窄**——后两者牵动类型系统与选择器，
   量级不是一批。

**乙的最小交付（待本批 §三 汇报后细化）**：`int` → `str` 的转换语义、错误身份、
双路径一致、以及**不许顺手扩到浮点格式化**（那是另一个面）。

**本批选择结果（2026-10-14）**：四行复探表全部为既定边界拒绝，因此选择乙；本批只完成结果汇报、
缺口合并和范围冻结，未提前实现 `int → str`。下一批的最小范围严格限于该转换，不扩展到浮点格式化。

### 5.3 **不许**

1. **不许**把复探结果写成「已解封」而不给表；
2. **不许**在乙里顺手把 `int`→`str` 扩成「全套数字格式化」——**先把一个做完**；
3. **不许**用本批的结果替 20D/20E 做承诺。
