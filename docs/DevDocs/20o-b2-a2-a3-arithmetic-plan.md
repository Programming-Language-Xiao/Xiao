### 1.1 A2范围

1. `lint`的`+ - * / // % **`、比较和一元负号，逐项映射冻结草案§五/§六；
2. `//`/`%`使用floor配对和既有余数符号；除零013、负指数009；
3. `0**0=1`；非负整数值指数、指数上限和结果预算按F-4/F-3；
4. 混合类型沿用既有数值提升；两个整数仍返回整数族，不新增隐式窄化；
5. 比较、相等和哈希不使用`f64`或显示文本字节；
6. bool±lint沿既有奇偶契约，只读符号/最低有效位；最大合法lint不得因i128解析上限失效；
7. 失败无部分结果、输入不变；错误顺序按F-12。

### 1.2 A3范围

1. `lfloat`加减乘、比较、一元负号和规范身份；
2. 语言`/`只返回精确有限十进制；非终止按F-12报034，不实现显式`lfloat_divide`；
3. 精确除法先按gcd约分，再处理2/5因子；工作中值≤W，最终系数≤D，scale≤H；
4. F-4开放域`//`、`%`、`**`：floor配对、`%`不物化完整商、非负整数值指数、0/±1快路径；
5. 混合类型按既有提升到lfloat；仅提升到float/sfloat的组合继续拒绝；
6. 显示scale、规范scale和结果scale按F-10；不为通过预算丢显示精度；
7. 强消去、`1.00/2`、负数floor进位、`1e100000 // 1e-100000`和`%`独立预算设计算例必须核对。

### 1.3 明确不做

- 不写A4转换矩阵、A5全链路、A6性能或A7收口；
- 不实现`lfloat_divide`、`cmath`、B2-B的intrinsic/ABI；
- 不新增intrinsic、不分配33～48、不改C ABI符号/布局/状态；
- 不改XCON格式、语言字典键或registry模块状态；
- 不运行B1旧721条F10，不把内核测试写成两后端/三平台产品成绩；
- 不用`f64`、字符串比较或i128近似替代精确整数运算。

## 三、分批执行

### A2-1：lint精确内核

1. 在A1适配层上实现lint加减乘、精确除法/整除/取模/幂；
2. `//`/`%`使用floor配对和既有余数符号；
3. 除零013、负指数009；`0**0=1`；指数域/上限/结果预算按F-4/F-3；
4. 两个整数仍返回整数族；混合类型沿用既有提升，不新增隐式窄化；
5. 每步先做工作值上界/实际结果预算检查，失败无部分结果、输入不变；
6. 不允许`i128`截断或`f64`近似。

退出：lint每个运算符/比较有边界+1、错误身份和输入不变证据；Runtime内核测试通过。

### A2-2：比较、一元负号与bool奇偶

1. 比较/相等/哈希使用规范数值身份，不用原文或`f64`；
2. 一元负号保留正确零/符号；
3. bool±lint只读符号/最低有效位；最大合法lint不因i128解析上限失效；
4. 不扩大bool与浮点、反向算子或其他隐式转换；
5. 失败错误沿F-12，不新增错误身份。

退出：比较/一元负号/bool奇偶的边界和错误路径稳定。

### A2-3：lint资源与错误

1. 按F-3共同接纳公式检查输入、工作值、结果和指数；
2. 上限+1、强消去、最大D/W/H和结果预算；
3. 033资源、011分配、009域/溢出、013除零边界分开；
4. 错误顺序按F-12；预算检查先于结果构造；
5. 记录实际中间值位数与预算判定，不只记录最终结果。

退出：资源/错误/失败原子性证据完整；没有松上界拒绝合法强消去。

### A3-1：lfloat加减乘与身份

1. 实现lfloat加减乘、比较、一元负号和规范/显示身份；
2. 保留显示精度；`1.5`/`1.50`/`15e-1`共享数值身份；
3. 对齐/消去/scale差按F-3/F-10；工作值≤W，最终系数≤D，scale≤H；
4. 混合类型按既有提升到lfloat；仅提升到float/sfloat的组合继续拒绝；
5. 不用文本比较或f64。

退出：lfloat加减乘/比较/一元负号在内核级通过；显示身份和规范身份分离。

### A3-2：精确有限除法

1. 语言`/`只返回精确有限十进制；
2. 先按gcd约分，再处理2/5因子；分母含其他因子报034；
3. 构造工作值前检查d_A+|u-v|≤W、最终系数≤D、scale≤H；
4. 不物化巨大对齐值；不实现显式`lfloat_divide`；
5. 034与013、033、011分开；失败无部分结果、输入不变；
6. `1.00/2`、强消去、最大有限除法边界和上限+1必须核对。

退出：有限/非终止/除零/超限路径稳定；034只在非终止精确商出现。

### A3-3：`//`、`%`与幂

1. `//`/`%`按F-4开放域，floor配对；
2. `%`不物化完整商，按scale差使用有界模运算/虚拟补零比较；
3. `**`只接受非负整数值指数；0/±1快路径；非平凡指数≤1,000,000且受结果预算；
4. `1e100000 // 1e-100000`和`%`设计算例按F-3核对；
5. 结果为lfloat，显示scale按F-10；零规范化；
6. 不把`//`/`%`接入034或`lfloat_divide`。

退出：商余/幂的内核边界稳定；`%`不产生巨大中间商；无未登记类型组合。

### A3-4：lfloat资源与错误

1. 按F-3检查对齐、工作值、最终系数和scale；
2. 033资源、011分配、009域/溢出、013除零、034非终止分开；
3. 错误顺序按F-12；预算检查先于结果构造；
4. 失败无部分结果、输入不变；不丢显示精度；
5. 记录每个算例的工作上界/实际结果和失败路径。

退出：A3资源/错误/失败原子性证据完整。

### A2/A3-5：回归与证据

1. 运行A2/A3内核单元/边界/确定性测试；
2. 运行A1适配层回归和B1契约/资源回归，确认未破坏既有产品；
3. 不运行旧721条F10；不声称VM/native完整语言差分；
4. 保存实际命令、日志、源码树、平台和摘要；
5. A5全链路、A6性能、A7收口仍未开始。

退出：A2/A3内核测试和B1回归通过；A4/A5/A6/A7未开始。
