# 10. LLVM 原生后端

> 本阶段实现发布路径的编译核心：从统一类型化 IR 生成跨平台原生程序，并按需链接 Xiao Runtime。正式 `xiao build` 命令在第 11 阶段接入。

## 一级工程目标：生成原生目标

### LLVM 降低

后端把类型化 IR 映射到 LLVM IR，再由目标平台工具链生成可执行文件或共享库。原生构建不携带完整字节码虚拟机，也不依赖运行时 JIT。

原生后端消费前端已经确定的模块图，不重新扫描目录猜测依赖。第 11A 阶段接入锁定依赖图后，它作为模块图的附加输入进入同一后端接口；锁文件本身不是核心原生闭环的前置条件。外部包即使在构建缓存中存在预编译产物，其 `.xiao` 源码与 `config.xiao` 仍是规范契约。

### 运行时链接

只有使用了动态值、容器、表生命周期、错误诊断或其他运行时能力时，才链接对应的 Runtime 部分。链接器和 LLVM 优化应删除未使用组件。

## 一级工程目标：保持跨平台数值和错误语义

### 目标平台

跨平台目标覆盖 Windows、Linux 和 macOS；三平台可以按独立子里程碑逐个接入，不要求在原生后端第一次产出时同步完成。本阶段让后端只消费规范化目标描述与工具链适配接口，并负责目标三元组、ABI 和代码生成差异；第 11 阶段再实现主机路径、进程、工具链发现及 CLI 参数到该接口的接线。后端核心不能反向读取第 11 阶段的 CLI 对象。

### 固定宽度类型

`int`/`float` 固定为 64 位，`sint`/`sfloat` 固定为 32 位。`lint`/`lfloat` 采用与平台无关的高精度表示，不能直接暴露 C 编译器对“非标准位宽”的实现差异。

### 溢出处理

每个可能溢出的算术操作必须使用带检查的实现或前端证明安全；溢出时进入统一语言错误路径，不允许目标平台静默回绕。

## 一级工程目标：支持构建配置

### 构建模式

至少需要调试、发布和可诊断三种构建方向。优化级别、调试符号、运行时诊断钩子和 Runtime 裁剪不能改变语言语义。`xiao build -debug` 必须保留源码映射、错误堆栈和诊断事件所需元数据，并把调试激活位写入产物；产物启动时无需再次传参就必须打开独立诊断窗口。调试版原生程序必须内嵌或随产物携带启动独立诊断进程所需的组件，不依赖 `xiao` 启动器；即使普通构建选择 GUI 子系统，调试窗口也不能被抑制。普通原生构建的内建默认级别已经确定为 `-O0`；第 10 阶段先完成对应的可运行未优化闭环。共享优化级别、LLVM Pass、链接时优化和性能基线在 [15. LLVM 原生优化与链接](15-native-optimization.md) 中分期实现，不能反向阻塞 N0。原生后端直接消费类型化 IR，不为自身不使用的模块强制生成 `.xiaoc`。

### 常量嵌入

`const` 值在编译期求值后可以直接嵌入机器码或只读区；如果程序获取其地址或通过动态接口访问，后端可生成只读存储。

## 二级实现任务

### LLVM 映射

1. 为标量、元组、数组和表布局建立 LLVM 类型映射。
2. 为动态值、引用计数和 `Weak` 建立 Runtime ABI。
3. 将控制流、错误路径和释放计划降低为基本块。
4. 生成目标平台链接参数和调试信息。

### 产物验证

1. 对同一 IR 同时运行字节码和原生结果对比。
2. 检查生成程序不意外依赖完整虚拟机。
3. 检查未使用 Runtime 组件被裁剪。
4. 通过受控目标描述和测试适配器验证三个目标的固定宽度与错误行为；主机工具链自动发现留到第 11 阶段。
5. 暴露可供第 11 阶段调用的稳定构建接口，并用内部测试驱动器验证，不在本阶段复制 CLI 参数解析。
6. 为第 15 阶段预留规范化优化配置、Pass 报告、目标特化和可复现构建接口。
7. 将统一错误路径、源码映射、诊断事件和 `-debug` 构建标志降低到原生 Runtime ABI；不得让平台异常伪装成可恢复 Xiao 错误。
8. 为调试版产物提供独立诊断进程的启动入口和本地管道/套接字连接；启动器缺失、业务程序为 GUI 子系统或标准终端不可用时，仍不能静默取消调试窗口。

## 验收标准

### 原生验收

- 原生构建接口能生成目标平台可执行文件；正式 `xiao build` 命令在第 11 阶段验收。
- 双击或直接运行生成的程序不要求安装 Xiao 虚拟机。
- 资源释放、容器路径和错误类别与字节码模式一致。
- `build -debug` 产物能输出与字节码模式可比的错误码、堆栈位置和诊断事件，并在直接启动时自动打开独立诊断窗口；该行为不依赖 `xiao` 启动器，也不受 GUI 子系统设置抑制。
- 未启用调试的普通产物不携带强制诊断激活位，不会自动打开诊断窗口。

### 体积与性能验收

- 纯静态标量程序不会因为动态运行时能力而完整装载 Runtime。
- 构建产物的 Runtime 组成可以通过诊断选项解释。
- 未优化基线可以独立生成；第 15 阶段加入的任何优化级别都必须与该基线进行语义差分。
