## 二、原型范围

### 2.1 隔离位置

建议放在 `tests/research/concurrency/`（或等价的隔离目录），不加入
`core/rust/Cargo.toml` 的 workspace members，不进入 `xiao-runtime` 公共 API。若必须
使用 Rust 依赖，单独一个实验 crate/脚本，结果和源码一起提交，但不能被产品 crate
引用。

### 2.2 场景

1. **线程入口**：启动一个 OS 线程，传入标量和嵌套容器；join 后比较原值与副本，
   确认深拷贝隔离；线程内修改不得影响发送方。
2. **深拷贝失败**：构造中途失败的容器复制，验证已复制前缀按逆序清理，主错误保留，
   清理错误作为 suppressed 记录。
3. **`CrossThread` 拆分**：用最小事实记录“任务边界”和“线程边界”两个原因；同一线程
   内挂起/恢复不能产生线程边界；只有显式线程迁移才产生线程边界。
4. **候选 A 推导**：对固定类型集合生成接受/拒绝表；标量、不可变文本、递归只读容器
   接受；普通句柄、可变容器、含资源的动态值拒绝；无法证明的动态值在边界拒绝。
5. **原子共享句柄（只读）**：原子强/弱计数、弱升级竞态、最后强引用恰好一次析构；
   只读载荷并发读取。
6. **原子共享句柄（共享可变）**：显式锁保护的写入；取消等待锁；异常/取消时释放锁；
   最后引用析构顺序；锁与原子计数的内存顺序。
7. **取消/清理**：按 07-D §10.4 顺序模拟“标记取消 → 停止接纳 → drain → 安全点 →
   finally/drop → 释放边界值 → 汇总错误”，覆盖未开始、执行中、等待中、完成待回收。
8. **测量**：记录环境、重复次数、spawn/join、深拷贝、原子增减、锁竞争和对象头
   内存开销；结果表必须可复现。

### 2.3 与产品边界的关系

原型可以临时定义内部结构，但不得：

- 修改 `xiao-syntax`、`xiao-types`、IR、Runtime ABI 或标准库公开契约；
- 把原型结构体写成 `xiao-runtime` 的公开类型；
- 把 `Send`/`Sync`、`CrossThread` 拆分或原子句柄写成正式语言能力；
- 用原型通过来宣称并发实现阶段已立项。

原型结论只用于回答“是否进入实现阶段、首版 ABI 怎么冻结、共享可变是否保留”。

## 四、验收

1. **隔离**：原型代码不进入产品 crate/workspace 公共契约；`git diff` 不包含
   `xiao-syntax`/`xiao-types`/IR/Runtime ABI/标准库公开契约修改；
2. **场景**：§2.2 的 8 类场景都有可重复运行的原型或明确的“不可在本原型验证”说明；
3. **拆分事实**：任务边界与线程边界分别可观察；同线程挂起/恢复不产生线程边界；
4. **候选 A**：接受/拒绝表覆盖标量、文本、容器、普通句柄、共享句柄和动态值；
5. **原子句柄**：只读与共享可变分别覆盖强/弱计数、升级、锁、取消、析构；共享可变
   只通过显式共享句柄，普通句柄没有被隐式升级；
6. **取消清理**：四个取消位置与主/suppressed 错误顺序有可观察记录；
7. **测量**：环境、重复次数和结果可复现；成本表能回答是否值得进入实现阶段；
8. **文档**：结果、开放问题、风险和“是否建议立项”写入本文；未登记新阶段代号或 API。

## 五、不负责

- 不实现完整任务池、Actor、Channel、协程、`async`/`await`、`spawn`/`send`；
- 不修改语言语法、类型系统、IR、Runtime ABI、对象布局或标准库公开接口；
- 不实现官方并发容器；链表/树/观察者/图等模型冻结后再评估；
- 不把原型里的 `Send`/`Sync` 推导、`CrossThread` 拆分或原子句柄写成正式契约；
- 不替星崽决定是否进入实现阶段；原型结果只作为下一道裁定的输入。

## 七、风险

1. **范围蔓延**：原子共享可变 + 候选 A + 拆分事实很容易变成产品实现；原型只做
   最小可测量场景，不追求完整语言能力。
2. **把原型当 ABI**：原型结构体、锁和错误顺序不能直接复制到 Runtime；进入实现阶段前
   必须另立冻结。
3. **深拷贝与共享可变混淆**：默认跨线程仍是深拷贝；共享可变只走显式共享句柄，不能
   因为原型支持共享可变就放宽普通句柄边界。
4. **测量环境差异**：线程调度和锁竞争对机器敏感；必须记录环境、重复次数和方差，
   不能用一次结果冻结成本。
5. **未裁定前不立项**：原型通过不等于可以建立并发实现阶段；仍需 21A §3.2 与
   07-D §11.3 的其余条件。
