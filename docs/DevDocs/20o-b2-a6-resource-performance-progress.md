## 工具与待验收范围

独立测量工具以完整Xiao调用为时间窗口，先在同PID的Runtime/VM初始化后取OS当前驻留基线，再构造输入和预热一次；五批为五个新进程。校准原始样本全部保留，时间按repeat归一后取中位数，内存取保守高水位增量的最大值。

首批目录包含27个路径、77种规模，以Python标准整数及闭式公式提供独立黄金。覆盖密集加减乘、强消去、有限2/5因子除法、连续Fibonacci数的gcd/非终止判定、负数floor、极端scale非零模余、实际结果增长的幂、主要转换、比较/集合哈希和元组承载。输入/预热/验证/编译在计时外，输入/输出/上游暂存均计入OS峰值。线程与任务池/XCON往返也按固定输入测量；8项资源/ABI原子性及3项校准协议默认测试已通过。
