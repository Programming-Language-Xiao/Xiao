# 07-D. 并发模型研究：候选、成本与冻结前置

> **07-D 是研究标签，不是并发实现阶段。** [21A](21a-rc-cycles-and-concurrency-handoff.md)

> 并发实现必须等 07-D 输出可比较的研究结论、执行机制经决策基线确认，并另立独立阶段。
>
> **本批一句话**：**先把「线程 / 任务 / Actor / 多 Runtime」的代价和边界测清楚，
> 不写任何并发语法或 ABI。**
>
> 状态：**研究规划、待执行（2026-10-20）**。本批不改 `xiao-syntax`、`xiao-types`、
> IR、Runtime ABI 或标准库公开契约；20L 的 F-1–F-5 作为前置返工。

## 二、20L 审核返工项（先做）

### F-1 **20L 字典静态链接污染 set-only 程序（阻断）**

**CI 证据**：维护回归 `39442513478` 三平台原生作业全红：

```text
first_modules_match_native_results ... FAILED
set-alias 原生退出状态不符：
X06-RUNTIME-002 type_mismatch actual=set expected=字典
```

**本地复现**：`from stdlib.set import size as count` 的原生构建成功，运行报同一错误；
`--emit-llvm` 产物含 `xiao_runtime_value_dict_keys`/`dict_values` 的真实调用，
说明 set-only 程序被 `stdlib.dict` 静态链接/符号解析污染，`count` 最终执行了
`dict.size`。

**要求**：

1. 模块限定或隔离 set/dict 的同名自由函数（`size`/`is_empty`/`contains`），
   不允许后链接的字典实现覆盖 set；
2. 字典方法链接只在类型确认的字典方法接收者上触发；set-only 程序不得携带字典函数体；
3. 补 `set-alias`/`text-alias` 的原生回归，作为 20L 的门禁用例；
4. 三平台原生作业恢复绿后，才能把 20L 写成验收通过。

### F-2 **`run.sh` 的已知抖动分类模式与真实失败名不匹配**

脚本允许 `"(fail) Ctrl+D"*`，真实失败行是
`(fail) !inLF! 后空缓冲 Ctrl+D 结束整个会话，不重新进入单行`；前缀不匹配，
已知抖动会被判成非已知失败。自测用的是合成 `(fail) Ctrl+D`，覆盖不到真实名字。
要求按实际测试名（或子串）匹配，并让 `XIAO_GATE_SELF_TEST` 使用真实失败行；
对带 ANSI 的 Bun 输出先去色再分类。

### F-3 **私有字典动作仍在契约外**

`__dict_remove`/`__dict_keys`/`__dict_values` 不在 `intrinsics.json`，
没有 20AB 的移除验证/效果/能力元数据。要求登记为受控契约或明确为编译器私有动作并
给出等价证据；`contains` 已改为遍历 keys，保留。

### F-4 **推送与平台证据**

- 推送 `1393cea`（external 字典方法加载回归）并核销 CI；
- 平台复现四平台 + ordered summary 新运行号；
- 原生字典方法、`array_push`、私有字典动作的移除验证；

## 三、21A 已确认、本批不得改写的边界

1. **默认单线程非原子 RC**；跨 Runtime 能力必须显式表示，不能悄悄扩散原子语义；
2. **强拥有图是 DAG，不是森林**；共享/菱形合法，强环静态拒绝；
3. **`CrossThread` 是值级生命周期事实**，不是可发送能力；模型冻结前不得名称启发式产生；
4. **当前 `RefCountStrategy` 不是原子实现接口**；共享句柄需要独立对象头/句柄；
5. **`Arena` 不豁免强环**；区域分配是新的存储类别；
6. **并发实现后置**：07-D 只研究；实现必须是 B0/N0 之后的新独立阶段；
7. **复制/冻结/共享可变对象尚未冻结**；普通 `Clone` 是浅层句柄克隆，不是跨线程深拷贝；
8. **不新增 `Weak`/`spawn`/`send`/`async`/`await`/Actor/Channel 语法**；
   不预留不存在的阶段代号或 `std.concurrent` API。

## 四、研究问题与交付物

### 4.1 模型候选与成本矩阵

至少比较：

| 候选 | 语义 | 需要回答 |
| --- | --- | --- |
| OS 线程 | 多线程共享进程内存 | 调度/栈、竞争面、句柄边界、错误/取消传播 |
| 单线程任务/协程 | 可暂停恢复、同一线程 | 挂起语义、RC/Weak 可见性、I/O 等待、取消 |
| 任务池 | 复用工作线程 | 任务迁移、Send 边界、阻塞/饥饿、清理 |
| Actor/Channel | 消息隔离 | 消息复制/冻结、邮箱生命周期、错误传播、背压 |
| 多 Runtime/堆岛 | 每岛独立 RC | 跨岛值集合、隔离边界、启动/关闭、ABI |
| 组合模型 | 上述组合 | 哪些组合必须显式禁止，避免隐式跨线程 |

**矩阵列**：语义清晰度、RC/Weak 影响、错误/取消/清理、实现成本、ABI/IR 影响、
标准库依赖、可测试性、与 21A 边界的冲突点。

### 4.2 Send/Sync 与任务边界

- 「移动到另一个执行单元」与「多执行单元同时只读」分开讨论；
- `CrossThread` 是否拆成「任务边界」与「线程边界」两个事实；
- `Send`/`Sync` 或等价能力的名称、推导规则、动态值/容器的策略；
- 普通句柄、共享句柄、消息值三者的类型/ABI 边界；
- 不得把协程挂起/恢复自动等同于跨线程。

### 4.3 值传递：拷贝、序列化、冻结、共享可变

- 递归深拷贝的集合、动态值、资源句柄和错误对象处理；
- 序列化的稳定格式、版本、失败传播；
- 冻结共享的发布/可见性/失败清理，以及如何阻止别名修改；
- 共享可变对象是否需要锁、原子操作或不同的所有权模型；
- 普通 `Clone` 的浅层句柄克隆不得被当作跨线程复制。

### 4.4 竞争、错误与取消

- 可静态证明的竞争拒绝规则；只能运行时检测的稳定错误边界；
- 主错误/suppressed/释放顺序在 VM 与 LLVM 的一致验收；
- 取消、超时、线程退出、资源关闭的清理顺序；
- 与 07-B 错误展开、06B 表生命周期、20D 资源句柄的交互。

### 4.5 原子共享句柄的候选形状

只做研究/差分原型，不落地：

1. 原子强/弱计数存储与内存顺序；
2. 弱升级的非零检查并递增竞态；
3. 最后强引用的唯一销毁与对象头回收；
4. 载荷不可变/锁/访问同步；
5. 与字节码、LLVM、错误/清理 ABI 的一致性；
6. 与普通句柄的 ABI 分离点。

### 4.6 标准库与 20 系列边界

- 双向链表、树、观察者、图等结构是否值得官方库，Weak 语义先由内存/并发阶段冻结；
- 图结构不默认 Weak，必须先定义节点存活/边失效/ID 注册表；
- 20D 资源句柄、20L 字典方法等不得被包装层掩盖所有权/竞争规则；
- 不新增用户可见 API，直到模型冻结。

### 4.7 交付物

1. **模型比较记录**（矩阵 + 每个候选的最小差分原型或伪代码 + 成本/风险）；
2. **Send/Sync/任务边界候选定义**（至少两套可选，注明冲突点）；
3. **值传递/冻结/共享可变候选**；
4. **竞争与取消/清理验收方案**；
5. **原子共享句柄 ABI 前置清单**；
6. **对 B0/N0、IR、Runtime ABI、标准库的依赖清单**；
7. **推荐方案 + 仍需星崽裁定的事项**；
8. **新独立阶段的入口条件与阶段编号建议**（只建议，不登记）。

研究记录必须逐条引用 21A §3.1 的六项；不得把候选方案写成已冻结的语言 API。

## 六、验收

1. **20L F-1 关闭**：三平台原生作业恢复绿；set-alias/text-alias 有原生回归；
2. **20L F-2/F-3/F-4/F-5 关闭**：门禁分类、私有动作、推送/平台、文档；
3. **21A 验收 1–3**：DAG/菱形通过、强环拒绝、跨线程句柄拒绝、`CrossThread`
   只由显式事实产生，均有实跑证据；
4. **研究交付物**：21A §3.1 六项逐条有记录；模型矩阵含成本/风险/依赖；
5. **Send/Sync/值传递**：至少两套候选与冲突点，未写成已冻结 API；
6. **原子句柄**：ABI 前置清单完整，未实现产品原子计数；
7. **不越界**：本批无 `xiao-syntax`/`xiao-types`/IR/Runtime ABI/标准库公开契约变更；
   无 `Send`/`Sync`/`async`/Actor/`Weak` 语法；无新阶段代号/`std.concurrent`；
8. **推荐与裁定**：给出推荐方案、开放问题和新阶段入口条件，交星崽决定；
9. **文档**：07/21/21A/README 同步；研究记录与既有阶段文档不冲突。
