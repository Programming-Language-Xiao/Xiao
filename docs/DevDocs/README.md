# Xiao 开发文档

> 本目录是 Xiao 语言从规格冻结到可用工具链的开发主线。文档编号只表示推荐的依赖顺序，不代表交付周期或实现速度。

## 文档使用规则

### 规范状态

- **已确定**：来自当前讨论，后续实现应遵守。
- **实现约束**：为了让已确定目标可落地而必须满足的工程条件。
- **待定**：讨论还没有给出唯一答案，不能在代码中悄悄假定。
- **候选**：提供推荐方向，等语言设计确认后才升级为规范。

### 阶段拆分

每个开发阶段至少拆成两级：阶段目标是一级工程，下面的词法、解析、类型检查、运行时等是二级子工程。每个阶段文档都包含实现任务和验收标准，完成验收后再进入下一阶段。

编号表示长期依赖顺序，不表示一次会话、一次提交或一个短版本。一个编号阶段可以持续很多轮设计、实现和验证，也可以继续拆出多个子里程碑。当前最近的工程目标只到“稳定生成最小 Token 流”，不要求同时完成语法树、类型系统、集合、字节码或 LLVM。

## 当前已经确认的主线

### 语言定位

Xiao 默认是强约束的静态类型语言，同时允许被明确标记的动态值。源码可以通过字节码模式即时运行，也可以通过 LLVM 后端构建为不依赖虚拟机的原生程序。

### 核心语义

- 普通变量默认可变，第一次绑定后类型锁定；支持 `int a = 1` 等显式静态声明，动态能力不能悄悄污染静态变量。
- 绝对不使用追踪式垃圾回收；资源释放必须确定且可预测。
- `int`、`float` 默认 64 位；`sint`、`sfloat` 为 32 位；`lint`、`lfloat` 为不限位宽类型。
- 数值溢出直接报告错误，不采用静默回绕。
- 只允许 `bool` 位于左侧与整数进行 `+`、`-`、`+=`、`-=`：偶数保持、奇数翻转，结果仍为 `bool`；其他布尔数值混算报错。
- 容器数字索引统一从 `0` 开始；数组路径中的斜杠表示嵌套索引路径，例如 `int list[3/2]` 约束外层索引 `3`、内层索引 `2` 指向的元素。
- 异构数组可以包含整数、浮点、字符串、布尔值、数组、元组、集合、字典表和字典列。
- 集合使用 `{值, 值}`，元素唯一、无序且不能被索引；`set()` 是空集合，`{}` 是空字典表。
- 集合默认异构，也可以显式约束元素类型；所有元素都必须可哈希，数组、字典表和普通集合等可变容器不能作为集合元素。
- 集合运算沿用 Python，但并集使用 `+` 和 `+=`，不使用 `|` 和 `|=`。
- 除项目根的特殊配置文件 `config.xiao` 外，每个普通 `.xiao` 源文件是一个模块；源码写实际 `import`，目录自动形成纯命名空间，不需要 `__init__.py`，也不执行目录初始化代码。
- 项目根目录统一使用全小写 `config.xiao`，集中声明项目、直接外部依赖、包外导出、约束和运行时默认值；依赖部分只列直接依赖，完整依赖树由工具生成到锁文件。
- 包内符号默认不向包外公开，只有 `config.xiao` 明确列出的模块或符号构成公共接口。
- 虚拟环境管理直接集成进 `xiao`；`xiao venv` 默认创建逻辑名 `venv`、目录 `.venv`，自定义名称同时作为逻辑名和目录名。`venv` 创建后自动激活，`sync` 创建或补齐依赖后自动激活，并通过 Shell 钩子显示绿色 `$环境名$` 提示符前缀。
- `install`/`i` 不等同于 `sync`：有激活环境时直接安装到该环境，否则安装到全局环境；所有环境都引用同一个全局内容寻址缓存。
- `config.xiao` 复用 Xiao 词法/语法基础，但只能使用不可执行的声明式子集。
- 普通 ASCII 标识符直接书写；用反引号包裹后可以使用任意 UTF-8 字符作为标识符，引用时也必须使用反引号。
- 函数关键字统一为 `def`；表头和表字段顶格，只有代码块使用缩进。

## 尚未闭合的关键问题

这些问题会影响语法或运行时，必须在对应阶段开始前补充决策：

1. 动态变量的显式声明关键字，以及 `@f` 与 `free` 的最终语法。
2. `drop` 的严格调用顺序，以及无法证明的引用环如何诊断。
3. 并发的具体执行机制（线程、任务池或其他模型）；目前只确定数据竞争不能被静默接受。
4. 相对/通配/动态导入、包内可见性、循环依赖和 FFI 语法。
5. `[Table]`、`[[Table]]` 与配置文件表头的完整语法边界。
6. 不同数值类型如何参与集合相等性与哈希，以及是否加入 `frozenset`。
7. 依赖锁文件名称、版本约束算法、包来源和完整性校验格式。
8. 多个环境并存时 `sync` 的目标选择、清理多余依赖及版本纠正规则。
9. `sync` 与 `install`/`i` 的锁文件策略，以及全局环境和内容缓存的实际位置。
10. Shell 钩子的初始化/取消激活命令和不支持钩子时的降级行为。
11. `bool(value)` 是否作为 `value as bool` 的等价转换写法，以及字符串类型关键字最终使用 `str` 还是 `string`。

## 当前最近里程碑

### Token 最小闭环

第一个实现里程碑只要求：读取源码、维护字节偏移与行列号、识别少量基础 Token、输出 Token 流，并对非法字符给出稳定诊断。详细拆分见 [01-lexical-and-grammar.md](01-lexical-and-grammar.md) 和 [12-tests-and-milestones.md](12-tests-and-milestones.md)。

### 明确不在该里程碑内

语法树、类型推断、容器运行时、集合运算、字节码虚拟机、引用计数和 LLVM 后端都不属于 Token 最小闭环，不能为了展示效果提前塞入。

## 文档维护

每次确认一个语言决策，先更新本目录中的决策基线和受影响阶段，再修改实现。若实现发现规范冲突，必须回写“待定”或新增决策记录，不能只在代码里保留隐式行为。
