# 20O-B7. 哈希、HMAC、CSPRNG、AEAD 与 TLS 基础实施规划

> **B7 尚未开始；B2-C、B6 完成并通过安全审阅前置后才有 B7-0 探测/冻结入口。**
> B7 覆盖 `hash`、`hmac`、CSPRNG、AEAD、TLS 基础；不实现 HTTP（B8）、数据库（B9）。
> 不自研密码算法；使用成熟、审计过的依赖，默认安全、无静默降级。
> B7 必须经过独立安全审阅；未审阅通过前 registry/教程不得 verified，不跑旧721。

## 一、入口与范围

| 项 | 当前状态 |
| --- | --- |
| B2 | B2-C 最终公共收口尚未完成；B7 产品绑定其最终 ABI/Runtime |
| B6 | 原生工具批尚未完成；B7 按路线在其后 |
| B0 | D-12 方向已确认：成熟依赖、TLS默认校验、参数绑定、强制限额/超时、未经安全审阅不发布 |
| 本批目标 | hash/hmac/CSPRNG/AEAD/TLS基础 |
| 未做 | HTTP/网络协议栈(B8)、数据库(B9)、自定义密码算法 |
| 状态 | 五模块初始未登记；安全审阅和证据通过后按范围升级 |

B7 是 **安全批**，不是普通库批。错误默认值、随机源、密钥生命周期、侧信道和失败关闭必须由安全审阅签收，不能只靠功能测试。

### 1.1 要做

1. 探测成熟hash/HMAC/CSPRNG/AEAD/TLS候选实现、版本/特性/许可证/审计状态；
2. 冻结hash算法集合、输出编码/长度、流式/整块边界、错误；
3. 冻结HMAC算法/密钥/输出/比较方式、常量时间要求；
4. 冻结CSPRNG来源/失败行为/种子/并发/能力，禁止回退到可预测源；
5. 冻结AEAD算法/Nonce/AD/密钥/标签/失败关闭、禁止复用nonce；
6. 冻结TLS基础范围、默认证书/主机名校验、协议版本、超时/限额/取消、错误；
7. 实现五模块、教程/示例/错误/资源/测试向量；
8. 接通类型/IR/TAC/VM/LLVM/归档、std/stdlib双路径、能力/隔离；
9. 独立安全审阅、三平台/CI、registry只在审阅通过范围升级。

### 1.2 明确不做

- 不自研密码算法/协议/随机数生成器；
- 不实现HTTP/数据库/应用协议（B8/B9）；
- 不提供“跳过证书校验”“弱随机回退”“静默降级”开关；
- 不改变B2-B6数值/值模型/工具语义；
- 不新增未冻结能力位/错误码/intrinsic/ABI；
- 不提前升级registry/教程，不跑旧721；
- 不把功能测试通过写成安全审阅通过。

## 三、分批执行

### B7-0：探测、冻结与安全审阅计划

1. 探测hash/HMAC/CSPRNG/AEAD/TLS候选实现、版本/特性/许可证/维护/漏洞/三平台；
2. 冻结hash：SHA-2/SHA-3等算法集合、输出编码、整块/流式边界、输入上限、错误；
3. 冻结HMAC：算法/密钥长度/输出、常量时间比较、密钥清理、错误；
4. 冻结CSPRNG：系统源/失败行为/种子/并发/能力；禁止可预测回退；
5. 冻结AEAD：算法/Nonce长度/唯一性/AD/密钥/标签/失败关闭、nonce复用防护；
6. 冻结TLS基础：客户端/服务端范围、协议版本/密码套件策略、默认证书+主机名校验、SNI、超时/限额/取消、错误；不提供不安全跳过开关；
7. 冻结五模块签名/参数/返回/效果/所有权/能力/错误码/资源/性能预算；
8. 固定依赖直接/传递版本、特性、锁、许可证原文、审计来源、`--locked`构建；不自研算法；
9. 编写安全审阅清单：随机源、密钥生命周期、常量时间、nonce、证书校验、错误泄露、DoS/资源、日志泄密；
10. 五份教程草案/固定示例/registry候选（planned）；
11. 记录延期能力（HTTP、服务端TLS、协议扩展）。

退出：五模块算法/API/错误/资源/依赖/安全审阅计划冻结；未写产品。

## 六、风险与禁止

- 自研密码算法/随机数/协议；
- 提供跳过证书校验/弱随机/静默降级开关；
- HMAC比较泄露时序、AEAD nonce复用、认证失败泄露明文；
- CSPRNG源失败回退可预测源；
- TLS默认不校验证书/主机名；
- 日志泄露密钥/明文；
- 功能测试冒充安全审阅；
- 提前升级registry/教程或跑721。
