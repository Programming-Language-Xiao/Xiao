# 20O-B6. 正则、压缩与 fmt 扩展实施规划

> **B6 尚未开始；B5 完成或明确授权后才有 B6-0 探测/冻结入口。**
> B6 覆盖线性时间 `regex`、整块 gzip/zlib `compression` 和 `fmt` 扩展；不实现流式/安全/网络。
> 不改变 B5 数值语义、B4 json_value 或 B2 ABI；新原生依赖/ABI 增量在 B6-0 冻结。
> CSPRNG/TLS/HTTP/数据库仍后置；不跑旧721。

## 一、入口与范围

| 项 | 当前状态 |
| --- | --- |
| B5 | 数值库尚未完成；B6 按路线在其后 |
| B0 | D-11 regex/compression 方向已确认：成熟线性时间引擎；gzip/zlib 整块；输入/编译/输出/解压上限必备，流式后置 |
| 本批目标 | regex、compression、fmt扩展 |
| 未做 | 流式压缩、zip/tar、TLS/加密、HTTP、数据库、CSPRNG |
| 状态 | regex/compression初始未登记；fmt既有3项verified保留；新增范围验证后升级 |

B6 是 **原生工具批**，不是安全/网络批。正则和压缩必须默认拒绝超限/畸形输入，不能把宿主库默认行为直接暴露成语言契约。

### 1.1 要做

1. 探测候选regex/compression引擎、版本/特性/平台/许可证/依赖闭包；
2. 冻结regex方言/编译/匹配/替换API、线性时间保证、输入/编译/匹配限制、错误；
3. 冻结gzip/zlib整块压缩/解压API、输入/输出/解压上限、畸形/炸弹/截断错误；
4. 冻结fmt扩展函数，保留B1既有3项和verified范围；
5. 实现三模块、教程/示例/错误/资源/性能；
6. 接通类型/IR/TAC/VM/LLVM/归档、std/stdlib双路径、导出/移除/隔离；
7. 三平台证据、registry只在验证范围升级；
8. 形成B7安全批交接。

### 1.2 明确不做

- 不实现流式压缩、zip/tar、任意容器格式；
- 不实现TLS/加密/CSPRNG/HTTP/数据库；
- 不改B5数值/B4值模型/B2数值语义；
- 不新增未冻结能力位/错误码/intrinsic/ABI；
- 不提前升级registry/教程，不跑旧721；
- 不把B6扩成B7-B9。

## 二、开工闸门

1. B5完成或明确授权B6-0探测/冻结；产品实施等待B5收口；
2. B2-C最终公共收口完成，B4/B5值模型/数值边界稳定；
3. D-11方向、20P Day-1标准、依赖闭包/许可证/锁策略可读；
4. 当前fmt既有3项、registry verified、B1七库可复现；
5. 三平台目标/工具链/CI可用；
6. 唯一任务根、独立target/Runtime/缓存已建立；
7. 三模块精确API/错误/资源/依赖/教程未冻结项列入B6-0，不得先写产品后补冻结。

## 三、分批执行

### B6-0：探测、冻结与教程草案

1. 探测regex/compression候选引擎/版本/特性/平台/许可证/传递依赖/二进制体积；
2. 冻结regex：
   - 方言/语法子集、编译/匹配/替换/分组API；
   - 线性时间/无回溯爆炸保证；
   - pattern/输入/编译缓存/匹配次数/输出限制；
   - 编译/匹配错误、非法UTF-8/Unicode、锚点/大小写/多行语义；
3. 冻结compression：
   - gzip/zlib整块压缩/解压；不提供流式；
   - 输入/输出/解压后上限、比率/炸弹防护；
   - 截断/校验和/畸形/超限错误；
   - 是否提供原始deflate明确裁定；
4. 冻结fmt扩展：
   - 新增函数/格式选项；保留既有3项与verified范围；
   - 对齐/宽度/进制/填充/非法格式/资源上限；
5. 冻结三模块签名/参数/返回/效果/所有权/能力/错误码/资源/性能预算；
6. 若使用Rust原生依赖，固定直接/传递依赖、版本、特性、锁摘要、许可证、构建工具和`--locked`策略；不使用未固定默认特性；
7. 若需新intrinsic/ABI/生成器/.xiaoc/.xar身份，B6-0另立增量并冻结；不修改B2-B5历史快照；
8. 三份教程草案、固定示例、registry候选（planned）；
9. 记录延期能力（流式/zip/tar等）。

退出：三模块方言/格式/限制/错误/依赖/版本/教程冻结；未写产品。

## 六、风险与禁止

- 暴露宿主regex默认方言/超时/内存行为；
- 允许回溯爆炸或无界匹配；

- 未固定原生依赖/许可证/锁；
- 提前升级registry/教程或跑721。
