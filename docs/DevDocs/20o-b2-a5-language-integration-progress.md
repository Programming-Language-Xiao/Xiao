完整矩阵发现原生缺少名称复合赋值接线；现复用既有二元Runtime入口，成功后才写回。另修正TAC复合结果类别不应取右值类别的问题。语言失败用例验证原绑定未被部分替换。

普通赋值缺少锁定类型信息、合法const初始化漏数值转换的反例见`a5-binding-valid-counterexample.log`：原先1.50显示为1.5，随后高精度绑定取负报定宽溢出009。类型结果现传递写回类型，IR统一加入Cast。const仍保持既有可求值初始化范围，本轮只校正既有合法字面量的标签与显示。

其他开发失败（事件容量不足、独立黄金手算、测试误用常量池公开接口、无效隐式窄化用例及未使用导入）均保留原始记录；没有删除失败用例或放宽产品预算。
