## 采样协议与阈值

- 每端三种后端各 14 个组合。快照构建、读取、同名替换、删除使用 256、512、1,024 对合成输入。各操作负载固定执行 64 次。满额替换和超限负载使用 1,024 对、1 MiB 逻辑字节，并核对旧值、哨兵以及释放后可重新使用的配额。
- 各组合依次启动五个独立子进程，各用独占目录。每进程预热一次，按冻结的 50 ms 最低门槛、100 ms 校准目标、16 倍单轮增长上限和 `2^24` 重复上限记录所有轮次。每批取末轮总时长除以实际重复数，每组合取五批中位数。
- VM 快照计时覆盖 `EnvironmentSnapshot::from_pairs`。原生快照从有界注入入口计到进入语言回调。操作负载通过 Xiao 的单调时钟计时。峰值增量使用同一 PID 的驻留高水位减去采样前当前驻留量，取五批最大值。Windows 使用工作集，Ubuntu WSL 使用 `VmRSS` 和 `VmHWM`。
- 使用未舍入数值判定。VM 中位数 ≤10 s，原生各档 ≤2 s，峰值增量 ≤64 MiB，同一平台、同一后端、同一负载的适用相邻规模中位数之比 ≤3。 适用翻倍比覆盖 512/256 和 1,024/512，满额用例各只有一档。

- Windows 首次发布 Runtime 构建退出 0。取证脚本将 Cargo `-vv` 中的构建脚本文本当成 JSON，退出 1。续跑读取同一次构建的 JSON 事件，普通发布二进制构建和启动断言均退出 0。 [首次错误](logs/1d-rerun/preparation/windows-build-initial.json) · [续跑前源码核对](logs/1d-rerun/windows/source-before-build-resume.json)
- Ubuntu WSL 首次校验发现 2,098 个 blob 与 Git tree 不一致，取证脚本退出 1。Git 归档沿用了 Windows 的自动换行转换。关闭该次归档的转换后重新解包，10,705 个 blob 和执行位全部通过。 [首次校验](logs/1d-rerun/preparation/ubuntu-source-initial/source-before-build.json) · [重试归档](logs/1d-rerun/source-export-lf.json)
- Ubuntu LLVM 22.1.2 首次运行缺 `libz3.so.4`，退出 127。将缺失库解包到本批工具目录后，三个 LLVM 工具版本探测均退出 0。 Ubuntu 的 LLVM 工具和依赖均来自本批本地解包。 [首次准备](logs/1d-rerun/preparation/llvm22-setup.json) · [补齐依赖](logs/1d-rerun/preparation/llvm22-deps.json)
- 正式采样后，首次独立复核将原生链接回执的系统字符串编码按普通文本读取，两端各报告 11 项身份差异，复核脚本退出 1。按 Windows UTF-16 与 Linux UTF-8 解码后重算，两端差异均为零。正式样本使用原始文件。 [Windows 首次复核](logs/1d-rerun/windows/audit-initial.json) · [Ubuntu WSL 首次复核](logs/1d-rerun/ubuntu-wsl/audit-initial.json)

正式样本共 420 批，两端的所有正式批次均保留。

## 平台缺项

macOS 本机为 `unverifiable`。当前宿主提供 Windows 与 Ubuntu WSL，本批缺 `aarch64-apple-darwin` 的发布 Runtime、工具链和五批实测。后续在 macOS arm64 以本报告的产品提交与阈值补测。 [macOS 缺项回执](logs/1d-rerun/macos.json)
