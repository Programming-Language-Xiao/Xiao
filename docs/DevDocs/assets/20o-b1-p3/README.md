# 20O-B1 P3 本机守卫报告

工程期：20O-B1/P3。保存仓库版计数守卫脚本在 Windows 本机的 28 个逐例结果。

报告对应工作流与脚本的原始文件 SHA-256，并注明宿主和 PowerShell 版本。原始字节摘要
会受到检出换行符影响；它用于绑定本次输入，不能把不同平台的字节摘要直接当作语义差异。

复跑入口和依赖见 [门禁 README](../../../../tools/gates/README.md)。报告只模拟 cargo 输出与
退出码，不证明 VM/native 产品功能、Linux/macOS 原生或远端工作流通过。
三平台证据与冻结阻塞仍见 [B1 草案](../../20o-b1-freeze-draft.md)。
