# 20O-B2-A6. 资源、错误原子性与性能实施规划

> **这是 A6 的资源/性能实施规划；不写产品代码，不执行构建、基准或测试。**
> 入口为A5代码快照`f21715d3`及A5有效收口；A6尚未开始，A7整批收口、B2-B/C后置。
> A6只验收A1～A5已有的资源/错误/性能边界；不新增ABI/intrinsic，不实现`lfloat_divide`/`cmath`。
> A0的`result.json`失败身份仍保留；A0只以`closeout.json`作为有效收口。

## 一、入口与范围

| 项 | 当前状态 |
| --- | --- |
| A1～A4 | 依赖/身份、算术内核、转换内核已退出 |
| A5 | 类型/IR/TAC/VM/LLVM/承载全链路已退出；代码快照`f21715d3` |
| 版本 | ABI 1.18、`CODEGEN_VERSION` 20、活动intrinsic最大32、`cmath` planned |
| 资源常量 | D=32,768、W=65,536、H=100,000；F-3接纳/工作量公式 |
| 性能协议 | F-3 §6.2：VM release≤10s、原生O0/O3≤2s、OS增量≤64MiB、翻倍比3/5 |
| 历史 | B1旧721条F10只作历史；22C/22D及19/11/22债务独立 |
| 后续 | A6资源/性能；A7整批收口后置 |

A6的产品边界是**资源/错误/性能验收**，不是新数值能力。资源或原子性缺陷可以修复，但不能改变已签语义、ABI、intrinsic 或预算；如需改变，先回B2-FREEZE。

### 1.1 要做

1. 复核A1～A5的文本/系数/scale/指数/中间值/结果/工作量预算；
2. 复核上限+1、强消去、失败无部分结果、输入不变和错误顺序；
3. 按F-3 §6.2建立受控VM/原生O0/O3、独立进程、五批中位数、OS峰值和翻倍比测量；
4. 测量A2/A3/A4/A5主要路径：加减乘、精确/非终止除法、//%、幂、转换和承载；
5. 保存源码、锁、Runtime、工具链、目标、PID、输出路径和原始样本；
6. 完成B1契约/资源/A1示例回归；不运行旧721条F10。

### 1.2 明确不做

- 不实现A7整批文档/registry/教程收口或B2-C的721条重跑；
- 不新增ABI/intrinsic、不分配33～48、不改C ABI状态；
- 不实现`lfloat_divide`、`cmath`或B2-B的ABI 1.19/21；
- 不改B1产品、冻结预算、22C/22D断言或工作流阈值；
- 不把性能目标写成任意硬件保证，不用未校准/未验证样本补绿；
- 不用预算通过掩盖超限，也不为通过性能改语义。

## 二、开工闸门

A6执行前必须确认：

1. A5有效收口、代码快照和自审证据一致；A6未开始；
2. A1～A5的依赖、诊断、算术、转换、全链路和B1回归可复现；
3. 当前ABI1.18/生成器20/intrinsic最大32/cmath planned未变；
4. F-3资源公式和性能协议无未登记变化；
5. B1契约/资源基线可复现；旧721条F10仍标历史；
6. 唯一A6任务目录和证据目录已创建，不覆盖A0～A5归档；
7. 若需改预算、ABI、intrinsic、XCON或性能阈值，先回B2-FREEZE/相应批准。

## 三、分批执行

### A6-1：资源接纳与错误顺序

1. 复核原文、解析后系数、scale、显式指数、工作值和最终结果的D/W/H；
2. 上限+1、强消去、最大合法输入、零/负零和scale差；
3. 002/009/011/012/013/033/034按F-12顺序；033不等于011，034不等于013；
4. 失败无部分结果、输入不变；预算检查先于结果构造；
5. 复核A2/A3/A4/A5各入口的原子性，不只测最终值。

退出：资源/错误/原子性证据覆盖主要路径；没有松上界拒绝合法结果。

### A6-2：测量协议与身份

1. 固定VM/Runtime release、原生O0/O3、目标、工具链和锁文件；
2. 五批独立进程，每批预热一次；短操作repeat=1，否则校准到50ms/100ms，repeat上限16、总样本上限2^24；
3. 时间先归一再取五批中位数；OS驻留增量取保守峰值最大值，不用中位数掩盖超限；
4. 记录PID、唯一输出根、Runtime/缓存/产物摘要；不复用旧可执行文件；
5. 无可靠OS峰值/校准不足/平台缺失时明确标不可验证，不放宽预算。

退出：测量身份和协议可复现；不可验证项有明确记录。

### A6-3：A2/A3算术性能

1. 测量加减乘、精确/非终止除法、//%、幂；
2. 覆盖最大合法系数、强消去、2/5因子、不同scale、负数floor和%非零余数；
3. 线性组翻倍比≤3；乘/除/gcd/幂/模幂等≤5；只比较同路径、同优化、同输入族的n/2n；
4. 记录VM release、原生O0/O3和OS峰值；
5. 不把B1旧721条F10或A6新样本混成同一成绩。

退出：A2/A3主要路径有受控测量或明确不可验证记录。

### A6-4：A4/A5转换与承载性能

1. 测量整数族/lfloat/float/sfloat/str转换的主要方向；
2. 覆盖大数、最近偶数、下溢/溢出、向零截断和资源边界；
3. 测量TAC/VM/LLVM承载、常量和序列化/并发路径的额外开销；
4. 测量A1示例和B1契约/资源回归，不重跑721条；
5. 记录B1/A1/A2-A5回归和失败样本。

退出：转换/承载路径有性能或不可验证证据；无ABI/语义变化。

### A6-5：证据与收口

1. 汇总资源、错误、原子性、性能、内存和身份证据；
2. 分平台记录实际执行、未验证平台、失败样本和独立债务；
3. 复核无ABI/intrinsic/XCON/registry/cmath变化；
4. 明确A7和B2-B/C未开始；
5. 形成A7入口，B2-A整批仍未收口。

退出：A6资源/性能证据完整；A7未开始。

## 四、证据矩阵

| 层 | 必测 |
| --- | --- |
| 资源 | 原文/系数/scale/指数/工作值/结果、上限+1、强消去 |
| 错误 | 002/009/011/012/013/033/034顺序、033≠011、034≠013 |
| 原子性 | 失败无部分结果、输入不变、预算先于构造 |
| 时间 | VM release、原生O0/O3、五批独立、预热、校准、中位数 |
| 内存 | OS驻留增量保守峰值、≤64MiB、不可验证标记 |
| 翻倍比 | 线性≤3、超线性≤5、同路径/优化/输入族n与2n |
| 范围 | 算术/商余/幂/转换/承载；最大合法输入和边界 |
| 回归 | A1示例、B1契约/资源；旧721条不运行 |
| 边界 | 无ABI/intrinsic/XCON/registry/cmath变化；A7未开始 |

## 五、退出条件

1. A1～A5主要资源/错误/原子性路径有证据；
2. VM/原生O0/O3性能按F-3协议执行或明确不可验证；
3. OS峰值、翻倍比和五批中位数记录完整；
4. 未用预算/阈值修改掩盖超限或性能失败；
5. 未新增ABI/intrinsic/XCON/registry/cmath；
6. B1契约/资源回归通过；旧721条F10未运行；
7. A7和B2-B/C未开始；22C/22D、19/11/22债务独立；
8. A6证据完整，A7仍须另批收口。

## 六、风险与禁止

- 把CI绿色或旧报告当成性能证据；
- 不做预热/校准或只取单次结果；
- 用五批中位数掩盖OS峰值超限；
- 复用旧可执行文件、旧Runtime或覆盖输出目录；
- 为通过预算/时限改语义、删场景或放宽阈值；
- 把B1旧721条F10写成A6当前成绩；
- 把A6测量写成A7整批完成；
- 运行旧721条F10或关闭22C/22D债务。
