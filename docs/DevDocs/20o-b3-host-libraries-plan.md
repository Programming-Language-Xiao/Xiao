# 20O-B3. 简单宿主库实施规划

> **B3 尚未开始；B2-C 最终公共收口仍是前置。**
> B3 覆盖 `time`（UTC + sleep）、`args`/`cli`、`fs` 扩展、`env`、`log` 时间戳，按 B0 已确认方向推进。
> B3 不实现网络/安全/JSON/TOML/数据库，不改 B2 数值语义；新库必须先探测、冻结、教程和证据，不能直接写产品。
> 历史债务、B1 旧721、B2-C 721 均不在 B3 核销。

## 一、入口与范围

| 项 | 当前状态 |
| --- | --- |
| B0 | 总纲/D-1～D-22 已确认方向；B1 已交付 |
| B2 | B2-C 最终公共收口尚未完成；B3 产品实现须待其完成或星崽明确并行授权 |
| B3 目标 | 简单宿主库：time/args/cli/fs扩展/env/log时间戳 |
| 已确认方向 | D-8 time（UTC墙钟/单调钟/格式化/首批sleep）；D-9 fs权限/路径/覆盖/原子写；D-10 argv规则 |
| 未冻结 | env/log 精确API、能力位、错误身份、取消/超时、教程示例；B3-0 先冻结 |
| 未做 | B4 JSON/TOML、B5 decimal/fractions、B6 regex/compression、B7安全、B8网络、B9数据库 |

B3 是 **简单宿主库批**，不是 B2 数值批的延伸。B2-C 的最终公开收口未完成前，B3 只能做探测/冻结/教程草案，不能把产品写成已交付。

### 1.1 要做

1. 探测 time/fs/argv/env/log 的现有宿主能力、平台差异、错误和取消边界；
2. 冻结 `time`、`args`/`cli`、`fs` 扩展、`env`、`log` 的精确 API/错误/能力；
3. 为每个库编写可执行教程和固定示例；
4. 实现 `time` UTC/单调钟/格式化/sleep；
5. 实现 `args`/`cli` 的 argv/程序名/空参数/非法Unicode规则；
6. 实现 `fs` 扩展的路径解析、覆盖、原子写和错误；
7. 实现 `env` 读取/写入边界与非法Unicode；
8. 实现 `log` 时间戳/级别/输出边界；
9. 接通类型/IR/TAC/VM/LLVM/归档、std/stdlib双路径、能力/取消/移除/隔离；
10. 三平台证据、教程/registry 只在验证后升级。

### 1.2 明确不做

- 不实现 B4 JSON/TOML、B5 decimal/fractions、B6 regex/compression、B7安全、B8网络、B9数据库；
- 不新增 B2 数值语义、不改 ABI/生成器/intrinsic 1～48；
- 不把 sleep 实现成无取消/无上限的宿主阻塞；
- 不把 fs 做成无权限/无路径解析/无原子保证的任意文件访问；
- 不把 env/log 写成隐式全局/无上限/无能力位；
- 不提前升级 registry/教程，不跑 B1 旧721。

## 二、开工闸门

1. B2-C 最终公共收口完成，或星崽明确授权 B3-0 探测/冻结并行；产品实现仍等待 B2-C；
2. B0 已确认方向、20P Day-1 标准、D-8/D-9/D-10 与能力/错误/取消原则可读；
3. 当前标准库加载器/能力位/错误表/取消通道可复现；
4. B1七库20入口/17资源/双精确/28守卫可复现；
5. 三平台目标/工具链/CI可用；
6. 唯一任务根、独立target/Runtime/缓存已建立；
7. env/log 未冻结项已列入 B3-0，不得先写产品再补冻结。

## 三、分批执行

### B3-0：探测、冻结与教程草案

1. 探测 time/fs/argv/env/log 的现有宿主API、平台差异、能力位、错误/取消/资源上限；
2. 冻结 `time`：UTC墙钟/单调钟/格式化、sleep单位/零/负/取消/上限/能力；
3. 冻结 `args`/`cli`：argv不含程序名、程序名另取、空参数、Windows不二次拆引号、非法Unicode报错；
4. 冻结 `fs`：权限、`..`/符号链接解析、覆盖、原子写同目录替换、失败关闭、错误身份；
5. 冻结 `env`：读取/写入/删除范围、名称/值编码、非法Unicode、能力、错误；
6. 冻结 `log`：级别、时间戳格式/时区、输出目标、能力、资源上限；
7. 为五库各写可执行教程草案和固定示例，登记registry候选；
8. 记录未冻结/后置项。

退出：五库精确契约/教程草案/能力/错误/取消边界冻结；未写产品。

### B3-1：`time`

1. UTC墙钟/单调钟/格式化按冻结契约；
2. sleep单位/零/负/上限/取消；
3. 能力位/错误身份/超时；
4. VM/原生一致；三平台时区/精度差异按契约；
5. 单元/教程/边界测试。

退出：time内部可用；教程/registry候选未verified。

### B3-2：`args`/`cli`

1. argv不含程序名，程序名另取；
2. 保留空参数；Windows不二次拆引号；
3. 非法Unicode报错，不有损替换；
4. cli辅助只在冻结范围；
5. 三平台argv测试/教程。

退出：args/cli内部可用；无平台二次拆引号。

### B3-3：`fs`扩展

1. 权限/普通操作路径解析`..`/符号链接/覆盖；
2. 原子写限同目录替换，无法保证则报错；
3. 受限模式/能力位按冻结契约；
4. 错误身份/资源上限/失败关闭；
5. 三平台路径表/边界测试/教程。

退出：fs扩展内部可用；无无权限/无上限路径。

### B3-4：`env`

1. 读取/写入/删除范围按冻结契约；
2. 名称/值编码/非法Unicode；
3. 能力位/错误/资源上限；
4. 不提供隐式全局缓存；
5. 三平台测试/教程。

退出：env内部可用；能力/编码边界明确。

### B3-5：`log`时间戳

1. 级别/时间戳格式/时区按冻结契约；
2. 输出目标/stdout/stderr/能力；
3. 资源上限/非法Unicode；
4. 不隐式全局状态；
5. 教程/边界测试。

退出：log内部可用；输出/时间戳一致。

### B3-6：语言、双路径与承载

1. 五库类型/IR/TAC/VM/LLVM/归档；
2. `std.*`/`stdlib.*`双路径、导出/移除、普通包隔离；
3. 能力位/取消/超时/错误传播；
4. 并发值承载按既有边界；
5. B1七库回归；
6. 三平台VM/原生O0/O3。

退出：五库内部全链路一致；无第二套宿主语义。

### B3-7：证据、教程与收口

1. 五库单元/边界/三平台/教程；
2. 教程示例逐字进入CI精确入口；
3. registry只在验证范围升级；
4. 保留失败/不可验证平台；
5. B1回归/28守卫；
6. 形成B4交接（JSON/TOML）。

退出：B3内部收口；B4未开始；未升级未验证范围。
