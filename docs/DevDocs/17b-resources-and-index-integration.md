# 17B. 资源与索引接入

> **17 阶段的第二批。** [17A](17a-archive-format-and-codec.md) 已把 `.xar` 的物理格式与
> 索引钉死（确定性容器、唯一索引、先验证再暴露）。本批做
> [规范](17-xar-archive.md) §「资源与诊断对象」的 **`17.5`–`17.8`**，
> 外加 17A 审核转来的一项补强。
>
> **⚠️ 本文件当前只登记范围与前序输入，完整交接文档须在本批开工前补齐**——
> 待定决策不得借实施悄悄冻结（见 §三）。

## 一、范围（来自规范）

规范 [`17-xar-archive.md`](17-xar-archive.md) `:82-88`：

| 子任务 | 内容 |
| --- | --- |
| `17.5` | 收集**显式声明**资源并规范化逻辑路径，**不自动打包项目目录、密钥或环境变量值** |
| `17.6` | 将资源、可选完整调试符号和可选源码正文写为**独立内容寻址对象**，并在唯一索引中建立映射 |
| `17.7` | 验证标准发布包**只含紧凑源码位置映射**，显式调试包**不会改变程序语义** |
| `17.8` | 对**缺失资源、重复逻辑路径、摘要不匹配和未声明资源访问**建立稳定诊断 |

规范 `:47` 另有一条贯穿要求，直接约束本批的收集面：

> 应用资源只收录 `config.xiao` 或将来冻结的单文件打包参数**显式声明**的路径，
> **不扫描并复制整个项目目录**；资源以内容摘要为物理名称，索引负责把它映射回
> 经过规范化的逻辑路径；**密钥、环境变量当前值和未声明文件不得被自动打包**。

## 二、已登记的输入（前序批次转来）

### 2.1 **17A 的负例覆盖缺口：六类**（来自 17A 审核）

17A 的 §2.6 把「安全拒绝面」写成**硬验收**（「规范 `:59` 列的**每一条**都要有负例测试」），
但审核实测下来，**实际断言只覆盖了 7 类，缺 6 类**：

| 规范 `:59` 要求 | 17A 实测状态 |
| --- | --- |
| 路径穿越、绝对路径、重复物理成员、ZIP bomb、加密、多卷、截断 | ✅ 有断言 |
| **重复索引** | ⚠️ `DuplicateIndex` **有实现无断言** |
| **索引内逻辑路径（空段 / `.` / `..`）** | ⚠️ 有实现（`xiao-xar/src/lib.rs:585`/`:607`）**无断言** |
| **反斜杠穿越** | ❌ 无实现也无断言 |
| **缺失索引** | ❌ 无断言 |
| **越界长度** | ❌ 无断言 |
| **未知必需版本** | ❌ 无断言 |

**为什么值得单独登记**：

- **前两类是「有实现、缺断言」**——代码是对的，但没有测试锁住它，将来被改坏时无人发现。
  这正是 [12A](12a-stage-acceptance-audit.md) §2.3 总结的**全仓最常见的缺口形态**；
- **「反斜杠穿越」是 §2.6 明文点名的**（「平台相关反斜杠穿越」），需要**补实现**而不只是补断言；
- **「缺失索引」与「越界长度」** 关系到验收 2「恰好一个索引」的落地强度；
- **「未知必需版本」** 对应规范 `:59` 的「未知必需版本」拒绝。

**归属本批的理由**：它们是**读取路径的拒绝面**，而本批要处理资源与逻辑路径，
与索引/路径校验同一批代码；分开做会两次触碰同一处验证逻辑。

**动工前须确认**：这六类里哪些是**补断言**、哪些需要**补实现**（「反斜杠穿越」已知需要）。
**不得**把「有实现无断言」当成已完成。

## 三、待定决策（**不得擅自冻结**）

- **资源声明的语法与载体**：规范说「`config.xiao` 或将来冻结的单文件打包参数」，
  但**具体语法未冻结**——是扩展现有 `config.xiao` 的某个表，还是新增打包参数；
- **调试包的形态**：「可选完整调试符号」与「可选源码正文」是**同一开关还是两个**、
  是否允许只带其一的组合；
- **紧凑源码位置映射的边界**：`17.7` 要求标准发布包「只含紧凑源码位置映射」——
  「紧凑」的判据需要冻结（体积上限？去掉什么字段？）；
- **未声明资源访问的诊断时机**：运行期拒绝还是**打包期**就拒绝（规范 `:47` 的
  「不自动打包」偏向前者，但 `17.8` 的诊断要覆盖它）。

## 四、与其他批次的边界

- **不重开** 17A 的容器格式、成员布局、`ArchiveIndex` 的字段 1–12（17A 已冻结）；
- **不做**入口解析与运行器（`17.9`–`17.13`，归 **17C**）；
- **不做**平台文件关联与调试窗口（`17.14`–`17.18`，归 **17D**）；
- **不做**数字签名与信任链（规范 `:61` 明写属待定安全决策）；
- **不重开** 14A 的 `.xiaoc` 格式与 16B 的引用集合口径。
