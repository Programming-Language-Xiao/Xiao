# `tests/spec`

存放语法、类型、容器、配置、模块、字节码和归档的规范正反例及期望诊断。工程期 01–19 按阶段持续扩展；测试输入与语言文档保持一一对应。

当前已落地的前端快照分为两个层级：`01-lexical/` 验证 L0/L1/L2 Token，`02-parser/`
验证严格最小 P0 AST、顶层语句、文档注释和错误恢复。每个子目录都有自己的 README，
说明快照格式、测试入口和不负责事项；后续阶段不得把未冻结语法混入这些快照。
11A-E3A 的 `11a-source/` 和 `11a-jcs/` 分别保存源语义正反例与跨语言共用的 JCS 向量；
两个目录的 README 记载 Rust 真实加载入口。
