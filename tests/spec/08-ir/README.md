# 08-ir 结构规格快照

本目录承载阶段 08 已冻结的类型化 IR 结构契约：入口模式、顶层语句形态、版本和表
签名/选择计划的数量，以及 JSON 快照往返。它验证 AST、类型和生命周期结果进入 IR
后的公共结构，不执行字节码、原生后端或 Runtime。

`structure.json` 用十个独立样本覆盖文档列出的七组选择器形态：多项精确路径、多项
区间、四种单边范围、全选、带步长全选以及两种随机模式；harness 同时检查语法选择项
类别和规范化计划的静态路径/步长/放回标记。

快照采用既有结构快照的第三代变体：顶层为 `stage`、`status`、`cases`，每条用例以
`source` 配合 `ir` 结构摘要表达期望，不另造第四套通用正反例 schema。执行入口是
`core/rust/crates/xiao-ir/tests/structure_snapshots.rs`，删除夹具或破坏 IR 降低/验证
都会使测试失败；后端性能和双模式一致性仍归各自测试层。
