# `xiao-diagnostics` 二进制入口

本目录只包含独立诊断终端进程的启动入口。进程通过本机回环套接字接收
`xiao_diagnostics::window` 的长度前缀结构化消息，渲染滚动事件区和固定状态栏，
不执行用户代码，也不参与 Xiao 语义判断。

## 工程期

11X0-D：`-debug` 运行时诊断窗口与调试产物激活位。

## 职责与边界

入口只负责连接 Runtime、校验一次性令牌、显示事件和最终指标；终端候选选择、
Runtime 事件生产、文件日志与退出码语义由调用方负责。本目录不解析 Xiao 源码，
不启动 GUI 框架，也不反向执行用户代码。
