# `xiao-diagnostics`

## 目录职责

定义 `XiaoError`、错误码、`message_id`、结构化参数、原因链、源码标注、诊断事件和退出边界。编译器、VM、Runtime、CLI 通过这些结构交换错误，不依赖译文。

## 工程期

07 建立错误模型；08 接入前端；11/11C 接入 CLI、日志、调试窗口和本地化。

## 模块放置

错误类型、错误码、原因链、诊断事件、源码标注和结构化输出适配放在 `src/`；具体语言目录由 `xiao-i18n` 提供。

## 禁止事项

不在这里拼接平台专属文本，不把错误翻译结果当作机器身份，不执行语言包代码。
