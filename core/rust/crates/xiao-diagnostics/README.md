# `xiao-diagnostics`

## 目录职责

定义 `Diagnostic`、统一 `XiaoError`/`FatalError`、错误码、`message_id`、结构化参数、源码标注、调用栈和报告记录；`window` 模块还定义 11X0-D 的诊断帧、事件、激活位和日志等级边界。01 阶段先供源码读取和词法器使用；07-A 完成错误核心与文本报告接口，11X0-D 接入独立终端进程。

## 工程期

01 提供前端最小诊断基础；07-A 建立统一错误模型、Fatal 边界、堆栈和报告器；08 接入前端；11/11C 接入 CLI、日志、调试窗口和本地化。

## 模块放置

诊断类型、严重级别、错误码、源码标注和结构化输出适配放在 `src/`；`src/window.rs` 负责跨进程帧和调试激活位，`src/bin/xiao-diagnostics.rs` 只负责终端渲染。具体语言目录由 `xiao-i18n` 提供。`Diagnostic` 的 `code`、`message_id` 和 `params` 是语言无关机器字段，`message` 只作为当前语言的预览文本；参数不得从已渲染句子反向解析。

## 禁止事项

不在这里拼接平台专属文本，不把错误翻译结果当作机器身份，不执行语言包代码。
