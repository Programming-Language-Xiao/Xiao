# `xiao-diagnostics`

## 目录职责

定义 `Diagnostic`、错误码、`message_id`、严重级别和源码标注的最小结构。01 阶段先供源码读取和词法器使用；第 07 阶段在不改变机器字段语义的前提下扩展 `XiaoError`、结构化参数、原因链、诊断事件和退出边界。

## 工程期

01 提供前端最小诊断基础；07 建立完整错误模型；08 接入前端；11/11C 接入 CLI、日志、调试窗口和本地化。

## 模块放置

诊断类型、严重级别、错误码、源码标注和结构化输出适配放在 `src/`；具体语言目录由 `xiao-i18n` 提供。

## 禁止事项

不在这里拼接平台专属文本，不把错误翻译结果当作机器身份，不执行语言包代码。
