# `xiao-ir` 测试

本目录覆盖 08-U0 类型化 IR 的降低、递归结构、稳定 JSON 快照和不变量验证。
测试只消费公开 API，不执行 Xiao 用户代码；每个新增 IR 语义必须同时补充正例、
非法结构例和快照回归。对应开发阶段为 U0-B/U0-C；本目录只放规格测试和夹具，
不放生产实现或后端代码。

`r2_release_reconciliation.rs` 对应 09R2，锁定 `reconcile_release_plans` 的
校验价值：释放计划是「作用域 × 退出边」的无条件笛卡尔积，覆盖类断言恒真，
只有实际发出的释放序列逐条比对才有效。用例覆盖重排、漏放、类别改写、未知
作用域、未知退出边名称和下标无关比较。
