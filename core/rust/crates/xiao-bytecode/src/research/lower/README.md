# `xiao-bytecode/src/research/lower`

放置 `IrProgram` 到统一三地址模型的单向降低规则，对应工程期 09R2。按关注点
拆分：`mod.rs` 只做状态与装配，`stmt.rs` 负责语句与块结构重建，`expr.rs` 负责
表达式展开，`plan.rs` 负责退出点上的释放计划接线；`tables.rs` 预登记表方法、装配
字段初始化函数并降低声明、构造与静态方法调用。表签名来自 IR，释放仍消费原计划。

禁止把语句、表达式、释放和签名重新堆回一个中心文件；也禁止让降低器重新推断
类型、重算生命周期或复制释放动作序列。块结构按语句结构重建，不把
`IrBasicBlock` 当作块划分依据。
