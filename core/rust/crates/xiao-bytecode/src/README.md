# `xiao-bytecode/src`

22E 的并发最小 feature 取自 `xiao-ir` 与 `xiao-runtime-abi` 的同一推导，`.xiaoc`
使用独立右移位表。当前 Runtime 身份不等于显式多 Runtime；读取器仍验证实际计划
所需位和旧版本要求，不放宽未知位、缺位或 ABI 拒绝。

放置生产指令集、常量池、模块元数据、验证器输入和内存编解码实现。对应工程期 09、14；
不放解释循环，正式 `.xiaoc` 容器仍归第 14 阶段。

普通程序继续使用内存布局 3；22C-FIX.1 并发计划使用布局 4 和追加的通用 opcode 50。
`concurrency.rs` 统一校验调用计划、参数类型和 IR 边界/取消事实。`research` 子目录只提供
迁移期兼容重导出，生产调用方使用本目录的根模块。
