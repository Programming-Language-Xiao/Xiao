# `xiao-bytecode`

## 目录职责

定义字节码指令、常量池、函数/模块元数据、验证输入和 `.xiaoc` 读写接口。这里不实现解释循环。

## 工程期

09 建立内存指令流；14 冻结分段 `.xiaoc` 格式、源码映射和完整性验证。

## 模块放置

指令定义、常量池、函数/模块元数据、编码器、解码器和验证输入放在 `src/`；解释循环放在 `xiao-vm`。

## 09R 研究边界

09R2 起在 `src/research/` 建立研究用统一三地址模型、指令模型、寄存器类别、调用签名表和
编码器。该子模块属于 09R 特别研究工程，**不是稳定语言接口**：试验性指令、寄存器结构和
编码在 09R3 冻结前不得对外暴露，也不得被 `xiao-driver` 或 CLI 依赖。研究产物不得使用
`.xiaoc` 扩展名落盘，正式分段格式仍归 14 阶段。

冻结结论与施工顺序见 [09R. 字节码寄存器机型特别研究](../../../../docs/DevDocs/09r-bytecode-machine-research.md)。

## 禁止事项

不在字节码层重新定义类型或释放语义；公开文件必须经验证器通过后才能交给 `xiao-vm`。
