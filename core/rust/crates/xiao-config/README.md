# `xiao-config`

## 目录职责

解析 `config.xiao` 的不可执行声明式子集，生成项目、依赖、导出、CLI、Runtime、Debug 和 Language 的规范化配置树。

## 工程期

05 建立配置节点；11 接入项目/全局配置；11A 接入依赖与环境；11C 接入语言；18 接入优化和归档参数。

## 模块放置

配置读取、声明式语法白名单、字段模式、来源合并和规范化输出放在 `src/`；CLI 写回流程放在 `cli/ts/src/config`。

## 安全边界

读取配置不能执行函数、控制流、导入或项目代码；未知字段、重复键和类型错误必须在执行前诊断。
