# `xiao-modules`

## 目录职责

按 `.xiao` 文件建立模块身份、目录命名空间、导入图、包内顶层再导出和确定性初始化顺序。
当前 05-B/05-C 分析项目根本地源码，并把 `[Table]`/`[[Table]]` 登记为可导出表符号；包外导出清单、`config.xiao` 依赖、下载和环境物化留给
`xiao-config`/`xiao-package` 后续阶段。

## 工程期

05-A/05-B、08；11A 接入锁定外部包图和环境视图。

## 模块放置

模块身份、目录命名空间、导入图、导出表和初始化排序放在 `src/`；表符号和方法体作用域
沿用发现/解析边界，不复制类型检查；集成规格测试放在 `tests/`；包源下载和环境物化放在
`xiao-package`。05-C 表回归位于 `tests/c05_tables.rs`。

## 禁止事项

不读取或解释 `config.xiao`、不下载包、不修改 Shell 状态、不执行目录初始化代码；模块至多
初始化一次的规则由 Runtime/VM 实现。解析器、类型检查器和 CLI 只能通过公开模型连接。
