# `xiao-modules/tests`

## 目录职责

存放 `xiao-modules` 的本地项目发现、命名空间、导入绑定、再导出和依赖图集成规格测试。
测试通过隔离临时目录写入最小 `.xiao` fixture，只调用 crate 的公开
`analyze_project` 接口，不执行模块初始化、Runtime、包下载或 CLI。

## 工程期

对应 05-B；后续 08 前端、09 Runtime 和 11A 包管理阶段应在各自测试边界增加消费者测试，
不要把后置行为塞回本目录的静态发现契约。

## 测试登记

`d0_modules.rs` 覆盖文件到模块名映射、根/嵌套 `config.xiao` 边界、点目录、大小写与
文件/命名空间冲突、块作用域导入、顶层再导出、缺失目标/符号、循环和限定访问边。
