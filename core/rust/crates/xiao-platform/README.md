# `xiao-platform`

## 目录职责

封装路径、进程、动态库、终端、诊断窗口、工具链发现、文件关联和原生目标的操作系统差异。公共接口使用 trait/能力描述，不泄漏平台实现。

## 工程期与顺序

10/11 建立抽象；正式适配顺序为 Windows → Linux → macOS；19 完成跨平台发布验收。

## 模块放置

能力 trait 和测试替身放在 `src/common`；系统专属调用严格放在对应平台目录；任何公共语义变更必须回到语言核心评审。

## 子目录

- `src/common`：平台无关能力和测试替身。
- `src/windows`：第一适配平台。
- `src/linux`：第二适配平台。
- `src/macos`：第三适配平台及 Apple SDK/签名探测。
