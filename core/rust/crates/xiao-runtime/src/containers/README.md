# `xiao-runtime/src/containers`

放置数组、元组、字典表、字典列和集合的运行对象。对应工程期 09R2，补齐 06-B
留待"后续 03 容器按子目录接入"的那一块。

## 结构

每个容器沿用 `tables/` 已确立的两层范式：**私有载荷**（`ArrayObject` 等）持有
数据并实现 `ObjectPayload`，**公开句柄**（`ArrayHandle` 等）只提供窄接口。句柄
内部的 `StrongHandle` 与载荷引用都不对外暴露，读取必须经闭包，避免对象头或
载荷借用泄漏到语义层。

## 边界

本模块只做存储与读取，**不含选择器语义**：多选、区间、步长和随机选择属后续
批次，容器不解释源码标点。字典表不承诺顺序；字典列的顺序稳定。集合无序，
元素必须可哈希（判定见 `is_hashable`，规则与类型层 `hashability` 对齐）。

禁止在这里重新定义类型规则、生命周期顺序或释放计划；容器只按引用计数持有
元素，释放顺序由冻结计划决定。
