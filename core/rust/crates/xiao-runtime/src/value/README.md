# `xiao-runtime/src/value`

这里放 Runtime 标量、`str` 堆对象和统一 `RuntimeValue`。固定宽度标量保持内联，
字符串通过不透明强句柄管理。

`mod.rs` 只定义值的表示和读取；算术、比较、相等和显式转换统一放在 `ops.rs`，
它是 Runtime 唯一实现算子的地方，字节码 VM 和原生后端都经这里取值语义。

对应工程期 06-B 建立值表示，09R2 补齐算子矩阵。当前已实现同宽度数值的
`+ - * / // % **`、四个比较、语言级相等、四个冻结拼写的 `str -> bool`、
`bool -> str` 和数值宽度转换；跨宽度运算一律报错，要求后端先插入显式转换。
复杂容器值、`lint` / `lfloat` 算术留给后续阶段，不得在这里给出近似结果。
