# `xiao-runtime/src/memory`

## 工程期

06-B；11B-I1b 增加对象内存计量。

## 职责

这里放不透明对象头、强/弱句柄和可插拔引用计数策略。06-B 首版使用单线程非原子
计数，禁止跨线程传递；对象头字段和裸指针均不暴露给上层语义模块。后续 VM/LLVM
只能通过公开句柄接口接入，不能复制引用计数或释放逻辑。

I1b 的计量作用域使用原子存活/峰值字节计数，不改变句柄单线程约束。对象头在分配时
记录静态载荷与额外拥有的容器/字符串存储，变长载荷变化后刷新，最后一个强引用释放时
扣除；共享句柄不重复计量目标对象。每次运行使用独立作用域，不把进程 RSS 当成 Runtime 峰值。
