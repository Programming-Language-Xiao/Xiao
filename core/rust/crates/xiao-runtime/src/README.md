# `xiao-runtime/src`

放置 Rust Runtime 的值、表、内存、引用计数、错误展开和测试驱动器。对应工程期
06-B；后续 03 容器、07 错误报告、09 VM、10/15 LLVM 和 11C 调试/国际化按子目录接入。

## 子目录

- `value/`：标量、`str` 和统一值。
- `memory/`：不透明对象头、强/弱句柄和计数策略。
- `tables/`：静态表签名与构造状态机。
- `containers/`：数组、元组、字典表、字典列和集合（工程期 09R2）。
- `errors/`：结构化 Runtime 错误和展开累加器。
- `testing/`：只用于规格测试的释放计划驱动器。
