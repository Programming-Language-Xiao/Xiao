# `xiao-vm` 测试

本目录覆盖 09R 研究子模块和 B0-B 生产入口的栈式载体解释器：结构化运行结果、运行指标、事件
接收器覆盖面和语义核载体无关性，对应工程期 09R2/09-B0-B。生产测试只消费已验证
`IrProgram`（经 `xiao-driver` 从源码编译得到）与三地址产物，不重新解析源码。

研究兼容入口与生产入口分别锁定语义核和执行契约。本目录只放规格测试和夹具，不放生产实现；
`b0_b_production.rs` 额外钉住前置验证、脚本/`[main]` 入口、报告源码位置和有界事件策略。

`r2_stack.rs` 保留栈式回归；`r2_vectors.rs` 驱动 79 条三机型共享向量；
`r2_selector_values.rs` 使用手工 TAC 让 `RunOutcome.value` 可观察，覆盖选择顺序、逐项
步长、范围、随机、来源根形状、字典列重复键、嵌套路径和空结果，并对三种载体各断言一次。

`r2_table_values.rs` 使用真实源码覆盖表构造、成员读写、私有字段、方法调用、初始化回滚、
析构错误与只读接收者、别名/容器/返回转移、致命故障和递归深度；同时验证两种编码宽度、
旧布局拒绝、表引用校验与函数编号稳定性。
