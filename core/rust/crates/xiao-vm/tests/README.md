# `xiao-vm` 测试

本目录覆盖 09R 研究子模块的栈式载体解释器：结构化运行结果、运行指标、事件
接收器覆盖面和语义核载体无关性，对应工程期 09R2。测试只消费已验证
`IrProgram`（经 `xiao-driver` 从源码编译得到）与三地址产物，不重新解析源码。

研究产物不是稳定执行接口；这些用例锁定的是语义核与载体的行为契约。本目录只放
规格测试和夹具，不放生产实现。

`r2_stack.rs` 保留 53 条栈式回归；`r2_vectors.rs` 驱动 31 条三机型共享向量；
`r2_selector_values.rs` 使用手工 TAC 让 `RunOutcome.value` 可观察，覆盖选择顺序、逐项
步长、范围、随机、来源根形状、字典列重复键、嵌套路径和空结果，并对三种载体各断言一次。
