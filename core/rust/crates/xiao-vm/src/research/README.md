# `xiao-vm/src/research`

放置 09R 特别研究工程的三地址解释器，对应工程期 09R2。研究代码**不是稳定执行
接口**：三种候选机型在 09R3 冻结前都不得被当作生产 VM 暴露，TypeScript 层也
不得依赖其中任何一型的内部结构。

按「机型无关语义核 + 可替换载体」两层组织：`semantics/` 只认识三地址指令和
`carrier.rs` 的窄接口，不认识「栈」这个词；`machine/` 下的每个文件是一种载体
实现。R2C 已接通当前帧 handler 路由、finally 子程序、错误传播、Fatal 隔离和运行时
检查；R2D 已加入分类型寄存器载体、混合窗口/求值栈载体；R2B 又接通高级选择、随机
和事务性广播；R2F1、R2G、R2H 分别接通集合代数/比较、`for` 迭代和表声明，
并让 79 条共享向量在三种载体上复用同一观察器。
`VmMetrics` 分开报告
溢出、栈映射和调用保存成本；VM 启动时
建立只读的 TAC `pc -> IrSpan` 表，错误帧使用物理 pc，缺失映射记录结构化事件。
这些仍是研究原型，09R3 冻结前不得作为生产 VM 接口暴露。

`RunOutcome.value` 是研究测试的可观察返回值，不承诺为生产执行接口；选择器的顺序、步长、
随机、根形状、嵌套和空结果由 `xiao-vm/tests/r2_selector_values.rs` 的手工 TAC 夹具锁定，
并在三种载体上复用同一份期望。

`stack_map_entries` 按 R1-F 冻结的**程序点数量**计数，语义核经 `map_point` 分派、
由各载体自己过滤：栈式数跳转目标、混合式数调用点与帧尾、分类型寄存器式恒为 0。
三种机型必须同量纲，否则 09R3 无法用这一轴对比；落帧槽与跨调用保存分别记在
`spill_count` 与 `call_save_count`，**不混入本指标**。
