# `xiao-vm/src/research/semantics`

放置机型无关的三地址语义核，对应工程期 09R2。实质实现位于父级生产
`src/semantics/`，本目录通过兼容路径暴露。它只认识三地址指令和 `../carrier.rs` 的窄接口，
**不认识「栈」这个词**——这是批次 2 能否只加载体文件而不改语义核的判据。

禁止在这里出现机型条件分支、载体专属词汇或逐指令观测回调；值运算一律经
`../ops.rs` 收口，不散落裸 `RuntimeValue` 调用。

`tables.rs` 是 `exec.rs` 的生命周期适配子模块，负责构造闭包、单例弱注册表和析构回调。
字段状态与类型校验交给 Runtime，方法执行复用同种载体的语义核；析构帧共享调用深度、
随机源、事件及错误队列，不借用外层执行器，不加入逐指令动态派发。
