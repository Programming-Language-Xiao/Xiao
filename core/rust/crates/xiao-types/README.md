# `xiao-types`

## 目录职责

提供静态类型、动态值边界、类型推断、显式转换、固定宽度数值、溢出检查、容器元素约束和布尔加减规则的编译期表示。当前 P2 首批实现覆盖标量声明、`const`、名称环境、HM 统一/泛化/实例化、转换矩阵和静态检查器。

## 工程期

02–04 建立基础类型；08 接入统一前端和 IR；后续由两个后端共同消费。P2 只检查语义，不执行程序。

## 模块放置

类型表示放在 `types.rs`，统一和 HM 操作放在 `unify.rs`，作用域放在 `environment.rs`，转换放在 `conversion.rs`，数值规则放在 `numeric.rs`，AST 检查放在 `checker.rs`，稳定编号放在 `diagnostics.rs`；后端布局类型放在各后端 crate。

## 禁止事项

不编码 LLVM 指令、不执行用户代码、不把平台 C 类型宽度当作 Xiao 类型定义。
