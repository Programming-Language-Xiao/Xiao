# `xiao-i18n`

## 目录职责

实现消息目录加载、语言标签规范化、回退、受限格式化和资源型语言包校验。它只处理系统文案，不改变 Xiao 语义或用户程序输出。

## 工程期

11C；后续服务 CLI、Runtime、REPL、`.xar` 启动和调试窗口。

## 模块放置

目录解析、回退和受限格式化放在 `src/`。当前仅在 `src/lib.rs` 中内置三条示范消息，
完整资源目录与资源型语言包插件尚待后续批次接入；不能把骨架当作完整双语目录。

## 安全边界

目录和插件只能提供声明式资源；版本、参数签名、来源和 SHA-256 必须经过校验，不能加载任意插件代码。
