# 22D-FIX.1 并发差分夹具

## 工程期

22D-FIX.1；由 `../22d_llvm_concurrency.rs` 加载，不单独生成测试二进制。

## 职责与边界

保存 C-1～C-9 的源码黄金场景和 C-11 的 C 布局探针。每个源码场景经同一前端产物分别
运行 VM 与 LLVM；不为测试增加生产分支，不新增语言 API 或 ABI。

本目录新增七个成功、七个错误场景；`worker-loop-bounded-stack` 的十万次有限循环
验证 ABI scratch 不随迭代累积；`native-wait-027` 验证 finally 和自定义 drop 各执行一次。
XCON 源码夹具逐字比较 64 KiB 往返和 16 MiB + 1 的启动前 029；64 层 tuple、
恶意 tag/节点/深度和宿主精确阻塞取消由 Runtime 单测登记，详见 22D §9.3。

detached 成功场景允许两条输出及独立打印临时对象交换先后；取消握手只对稳定共享对象
的销毁/弱释放序列作差分，临时轮询守卫单独确认存在。其余场景保留完整释放投影比较。
