# env 性能采样辅助模块

本目录存放 `b3_env_performance` 普通发布二进制的私有采样辅助模块。

## 工程期

20O-B3-4E：FIX-B 产品上的 env 五批性能复跑。

## 职责与边界

- `native.rs`：装配固定 LLVM 工具链，构建原生测量程序和 C 启动 shim；
- `process.rs`：启动独立采样子进程，完成预热、校准和原始日志归档；
- `workload.rs`：生成固定合成输入和 VM/原生共用的 Xiao 负载；
- `native.c`：只接入既有嵌入入口和输出采集，不实现产品语义。

这些模块仅供内部性能证据使用，不属于公开 SDK、C ABI 或标准库接口。
