# B1 受控性能测量实现

工程期：20O-B1-IMP-REM-C。职责：保存测量窗口、独立工作负载和进程内存读取。
边界：仅供显式示例工具，不加入语言、Runtime ABI 或标准库导出。

31 种负载覆盖 20 个入口，包括两种 Base64 模式、Unicode 填充/URL，以及 CSV 的全引号、
多换行和 1,024 字段；最大 CSV 记录的编码长度恰好 65,536 字节。
校准必须测实际固定批次达到 100ms，不能只用一次调用估算后声称满足最短采样窗口；
正式五次每批均要求至少 50ms，所有校准样本也保存在 JSON，失败保持红灯。

macOS首轮测量在math.abs的O3校准中撞上进程看门狗，报告仅一条且complete=false。
零或极短的时钟读数不能当作1ns计算任意大的倍数；现在每轮至多放大16倍，并记录校准进度。
默认性能测试共用校准模块，用250ns调用配1us量化时钟固定复现旧过冲，检查能收敛到正常批次。
60秒进程看门狗、50ms采样下限及产品F10预算均保持原值。

进程内存取当前 RSS/Working Set 和历史峰值；峰值减窗口起点的当前值是保守上界，
可能包含此前高水位，不会将它称为精确的分配器峰值。所有平台方法写入测量结果。
