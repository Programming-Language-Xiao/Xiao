# `xiao-optimizer`

## 目录职责

实现共享 IR 与后端降低前的优化 Pass、效果分析、验证、优化指纹和失败回退接口。当前已提供
规范化配置、O0–O3 占位、稳定指纹、只读事实摘要、IR 快照和验证阻断；所有变换必须保持 Xiao
的溢出、随机、I/O、错误和 `drop` 语义。

## 工程期

13 建立统一管线与边界输入；14 接入字节码优化和源码/未优化字节码/优化字节码三方差分；
15 接入 LLVM 原生优化。

## 模块放置

Pass 注册、效果/别名分析、验证、配置指纹和报告放在 `src/`；优化级别命令行解析放在 CLI。

`differential.rs` 同时提供 13A/13B 的四字段两侧比较和 14B 的三方比较。三方套件固定
比较输出、错误、随机序列和 `drop` 顺序，并按源码、未优化字节码、优化字节码三个执行
对象分别取样；当前优化级别由报告显式记录。

## 禁止事项

不解析 CLI 的 `-O` 参数、不写入不可变缓存、不用未定义行为假设替代语言规则。
