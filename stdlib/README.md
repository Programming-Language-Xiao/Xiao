# Xiao 官方标准库源码

工程期 20C；这里是官方 Xiao 标准库的规范源码根目录。首批 `text` 与 `path` 模块已按冻结接口落地。

## 职责与边界

- 负责保存官方库源码、模块级 README 和与阶段文档同步的兼容身份记录。
- 官方库由工具链专用加载器按固定命名空间提供，不作为普通包写入 `PackageRegistry` 或依赖锁文件。
- 本目录不放预编译发布对象、`.xar` 字段或普通包配置；预编译对象只允许作为本地构建缓存。
- 每个新增 `.xiao` 模块必须在本目录登记 README、UseDocs、DevDocs 阶段索引和兼容元数据，并由仓库检查器校验路径登记。

首批模块仍处于工程期验证：必须通过 VM/LLVM 双路径、移除验证和同步门禁后，才能作为发布 API 使用。
